# 1.8.0 自动交通与道路编辑修复

## 使用

- 选中道路，在右侧「自动交通」打开「启用自动交通」；道路绘制工具内也有同一组控件。默认关闭，不影响旧工程的性能或外观。
- 分别设置车辆（0–120）、行人（0–80）和普通同层路口的自动信号控制。道路太短、没有可用步道或没有安全出生位置时，实际生成数可以少于设置数量。
- 「播放交通预览」独立于时间轴；暂停会保留当前交通位置。「重置交通预览」回到初始分布。开始正式时间轴播放后，由时间轴接管；视频／PNG 导出按时间轴采样，结束后恢复原预览。工程保存数量、种子及控制开关，不保存每一辆车和每一个行人。
- 普通道路车辆靠右按车道行驶，有跟车间距和道路类型对应的速度；匝道减速，合流让主路。已连接路口可以转向，未连接的高架／下穿不会凭 XZ 投影自动相连。自由端车辆重新入场；行人在有步道的道路或园路上往返，高速道路不生成行人。
- 普通受控路口自动生成红／黄／绿显示，车辆黄灯及红灯不得新进入；行人有独立放行相位，路口未清空时继续让行。关闭信号控制后仍保留简化的冲突区预约与合流让行。
- 道路改线、删除、隐藏、撤销／重做或载入工程后，交通从可见道路重新构图；修改道路时暂时隐藏交通。交通是派生的实例化对象，不挤满模型列表，也不是数百个独立可编辑场景模型。

## 此次道路修复

1. **螺旋桥墩分布**：螺旋连接按半径收紧有效间距（6–10m，上限不超过用户指定间距），柱帽拟合真实路面底部；本路和其他螺旋道路采用实际三角面碰撞检查，减少被整段弯道 AABB 错误挡掉的支撑。保留低净空、已有道路等真实障碍的避让，并非每个采样站都强行插柱。普通道路的支撑间距规则不变。
2. **紧凑汇入口标线**：补上贴合路面的虚线导流；所有相关道路完成重建后再定位导流线，兼容载入工程的道路构建顺序。高速匝道口不添加斑马线或城市停止线，普通路口原有的斑马线／停止线保留。
3. **参数面板稳定**：道路属性更新作为一次事务，暂不显示内部进入／退出编辑器的过渡状态；数字框与下拉框聚焦时保留原 DOM 和输入。连续编辑使用最新道路对象，离开表单后同步整块面板，并保留当前道路面板的折叠和滚动位置。
4. **自动交通**：程序化实例化车辆／行人、车头沿道路与坡度朝向、道路类型约束、普通路口信号及简化转向。支持确定性时间回退，实例渲染同步使用回放后的新演员引用；资源在重新构建／清空时释放。

## 边界

这是用于运镜和场景参考的**简化交通预览**，不是交通工程或自动驾驶仿真。不包含动态超车／变道、复杂优先权规则、路径目的地分配、交警或真实交通密度校准；手动放置的装饰信号灯不接管自动路口控制。车辆不会自主绕过后来摆到道路上的建筑或模型。数量和安全距离是预览预算，不是现实道路容量认证。

时间采样为 30Hz 固定步进，交通采样时间上限为一小时。路网变更会重新初始化交通，不承诺保留某个个体的运行历史。测试环境为 Linux Chromium 软件 WebGL；不能代替用户 Windows / RTX4070Ti 的视觉与帧率验收。


四项综合浏览器回归是 `test/road-traffic-regression.mjs`：真实键盘连续输入、多次参数提交、桥墩实体接触检查、缓存／载入稳定性、汇入口标线、真实 UI 开关、红灯停车／绿灯通行、道路类型、实例化、保存／撤销／重做、暂停保持、反向 seek 的 GPU 实例同步及真实 PNG 导出清理。支持 `TEST_FILE_URL`（无网单 HTML）和 `TEST_URL`（桌面 CSP 前端）运行。证据见 `docs/road-traffic-evidence/`。
