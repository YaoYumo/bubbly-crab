# 道路检查器 · 预演辅助首版

2026-10-17。本文记录按序计划的第三项。后续夜景窗灯现已另行交付首版，见 [窗灯说明](window-lights.md)。

## 使用

1. 选中已完成的笔刷道路，在「物体参数」展开「道路检查 · 标高 / 纵坡 / 净空」。
2. 按场景自设参考阈值，点「运行检查」。默认纵坡上限 **10%**、不同道路净空下限 **4.5m**、地形穿入容差 **0.05m**；这些不是任何地区道路规范的自动取值或合格线。
3. 蓝线为道路**基准标高**，绿线为中心处实际地形三角面；横轴是世界坐标水平里程。基准线不是沥青或步道完成面。纵向自动缩放，图上的角度不能当真实坡度角。
4. 拖动站点滑块查看基准标高、有符号纵坡、中心地形及横断面最小净空；定位站点或点击问题区段可移动视角。橙色辅助球标示问题位置，关闭全局辅助显示时球不可见，但仍会定位视角。
5. 改道路或地形后旧结果会标记过期，不能再用旧坐标定位；重新运行后显示与**上次成功检查**的摘要差值。要看编辑前后变化，应在编辑前、编辑后各检查一次；不是后台自动记录编辑历史。
6. 支持取消、取消后立即重跑、导出 JSON；导出会标明报告是否已过期。

检查器不改道路、地形、材质、参数或撤销栈；报告、阈值、折叠状态和定位球仅在当前会话有效，不存入 `.previz`。主动点击定位会退出预览、停止视角自转并移动编辑相机，这是明确的视图操作。

## 计算口径

- 读取 `RoadTerrain.prepare` 已派生、含地形跟随及路口协调的 profile，而不是用原始控制点 Y 冒充成品高程。使用根节点世界变换后重算水平长度 / 三维长度和基准标高范围。
- 纵坡 = `100 × Δ世界Y / 世界XZ距离`，是百分比而非角度；最大值取所有派生 profile 段的绝对纵坡，而不只取图表的抽稀节点。垂直段的纵坡不可定义，单列提示；阈值比较有微小数值容差，避免恰好 10% 的浮点误报。
- 检查时按需建立实际道路及路口网格的 XZ 三角面索引，包含端帽、步道与批处理后的铺装；排除桥墩，不按渲染材质是否灰模来改几何判定。
- 自身路面取当前站点高度附近、朝上的实际三角面；相连路口的实际铺装也参与，缺口内没有任何实际路面时跳过。表面窗口为基准站点世界 Y 的 `−0.4～+1.5m`，近竖直面不参与，极端变换不保证完整覆盖。
- 地形检测使用当前规则高度网格的**实际三角面插值**，不是双线性 `heightAt`。例如鞍形网格的对角线可能高于双线性值；地形范围外不拿边缘钳制高度当作实际地表，并明确标记未检查的采样数。
- 净空 = 上方其它道路 / 路口真实几何最下方交点 − 自身实际路面最高交点。采用全部横断面采样点的最小值，**包含步道侧带**，不等同于车道专用净空。上下路基准标高至少差 0.8m 才按分层处理，同标高路口不报低净空；可发现短道路下穿上方路口铺装的情况。
- 桥墩沿用既有全体积碰撞与避让结果，只额外保存受阻未放置站点的种子位置。没有重写支墩搜索、间距、植被清除或支持缓存。
- JSON 的 `maxIntrusion` / 站点 `intrusion` 是 `地形表面Y−路面Y` 的有符号最大值，负数表示采样点地形都在路面下方，界面将负的“最大穿入”显示为 0；`null` 表示没有有效采样。`minClearance:null` 表示未采到符合分层条件的上方几何，**不是无限净空或判定通过**。

## 成本与边界

- 不逐帧重扫。每次检查最多 **1025 个纵向站 × 9 个横向点**；读取所有 profile 段计算纵坡。几何每 12,000 个三角形、采样每 24 个站点让出主线程，报告进度并检查取消 / 场景版本。
- 世界几何索引最多保留 800,000 个非近竖直三角面、1,500,000 个网格单元引用，单个过大范围也会中止并给提示。超预算不是检查通过。每次检查的几何索引仅局部持有，报告不留 Geometry / Material 引用。
- 同时只有一个任务，新任务会取消旧任务；UI 用独立请求身份防止旧 Promise 覆写重跑状态。保留最近 8 条道路的报告，报告最多记录 2,000 个问题区段，超过会显示截断；问题每页 40 条。定位复用一个辅助球。
- 监听 `objects`、`terrain`、`gizmo-live` 失效；选中变化隐藏旧标记。通过现有编辑 API 的移动、改参、撤销 / 重做、载入等都会走这些事件。外部脚本原地改几何 / 参数却不发事件不在保证范围内。
- 隐藏的其它道路 / 路口不参与。不是完整碰撞或结构求解器；不检查建筑 / 车辆 / 管线净空、同一道路自跨，也不保证多层自交、极端缩放 / 倾斜。细小障碍、采样间地形峰和横断面间隙可能漏检。预演草图中的铺装几何也不代表现实桥板结构。
- **未发现问题 ≠ 工程规范合格。** 这里的阈值、离散采样和几何诊断仅供预演调整。

## 已验证

源码和真实 `file://` 单文件专项通过（后者浏览器网络离线）：

- 水平米制长度、10% 纵坡、正负坡、垂直段、世界变换、阈值边界；纯几何测试也比对实际 PlaneGeometry 射线与鞍形地形采样。
- 固定道路被 2m 地形掩埋时测得约 **1.83m** 穿入；地形跟随读派生 profile；地形范围外明确不测。
- 3m / 8m 基准高差的交叉道路，测得保守横断面最小净空约 **2.70m / 7.70m**，不是简单拿基准高差；侧向重叠及架空路口下穿也检测到。
- 同标高路口不误报上跨、隐藏道路不参与、实际全体积碰撞造成的 **7 个受阻桥墩**可定位。
- 只读存档对照、10 条道路连续检查的 8 份报告上限、重复检查不增加 renderer 几何资源、取消 / 失效、原生 UI 取消后立即重跑、旧报告不能定位、前次摘要差值、改参后的撤销 / 重做，以及实际 `.previz` 工程包恢复和辅助标记不入存档。
- 已有道路参数真实点选、地形道路、区域规划、道路性能、建筑实例化及性能隔离专项通过；正式单文件道路参数 / 区域规划 / 照明专项通过。原路口门禁的本轮结果见 evidence 清单。

道路检查器交付阶段的报告、执行清单及当时 HTML 的 SHA256 见 [road-diagnostics-evidence/manifest.json](road-diagnostics-evidence/manifest.json)。当前正式 HTML 哈希以 `window-lights-evidence/manifest.json` 为准。旧 `ordered-development-evidence` 保留前两阶段当时的证据和旧 HTML 的哈希，不覆盖成新结果。本轮不是全部历史总门禁，也不是土木合规或硬件 FPS 验收。
