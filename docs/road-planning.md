# 道路绘制辅助与封闭区域功能填充

## 使用

Scene 页视口左上角的 **Grid / Snap** 可以直接切换；右侧 **地形 → 道路画笔** 也提供相同开关。

- **地面网格默认关闭**，开启后显示世界 X/Z 网格。网格贴合地形；水面高于地面时画在水面上方，避免被遮住。
- **道路笔刷捕捉默认关闭**，与网格显示完全独立。显示关闭时也可捕捉；显示开启时也可自由落点。
- 网格间距可选 1、2、5、10、20m，初始 5m。绘制落点、点位拖动与悬停预览共享同一捕捉逻辑。
- 开启捕捉后按住 Shift 落点，将新线段锁定到世界 X/Z 方向，方便直角绘制。需要尖角时关闭原有「平滑倒角」。
- 这些设置随工程保存，旧工程未提供该设置时按默认关闭处理。物体变换工具的旧吸附间距不受此开关影响。

完成道路绘制后：

1. 点击 **识别封闭区域**。只识别实际道路/路口占地包围出的可用区域，不用开放路网的包围盒冒充地块。
2. 通过区域下拉框或开启「视口选区」点击高亮地块选择；Esc 退出视口选区。
3. 选择 **住宅区 / 商业区 / 公共服务区 / 公园绿地**，选择建筑间距，点击 **填充选中区域**。
4. 可再次选择其它功能并填充，只替换该地块原来的自动生成内容；也可使用「清除本区填充」。

## 边界与安全规则

- 地块已从道路（含侧带）和路口占地退让 **2m**；退让后面积小于 25m² 的空间不作为可填充地块。
- 建筑保持模型的真实尺寸。完整占地包围盒（含屋檐、台阶等）必须位于地块内，且与其它物体不重叠；额外留 1m 建筑边距。
- 保留凹地块边界及内部独立道路岛；不能只验证建筑中心/四角，跨越凹口的建筑也会被拒绝。
- 一次最多生成 **40** 个对象，超出时均匀抽取候选位置。区域太小或已被占满会明确提示，而不是把建筑缩小或放到道路上。
- 手动放入的物体、锁定的自动生成对象均保留。若想让手工编辑过的自动生成对象不再被替换，请先锁定它。
- 填充/清除均可一步撤销和重做；对象及功能分区随工程 JSON 保存。重新填充不会无限叠加同一批建筑。
- 路网改变后旧选区立即失效，需重新识别；**不会自动搬移或删除已有建筑**，避免破坏已编辑场景。
- 网格、区域高亮是辅助层，不进入机位预览或成片导出。区域选择与道路/地形笔刷互斥。

## 实现与验证

- `src/road-parcels.js`：道路中心线约 2m 采样；Clipper 毫米整数偏移/并集，PolyTree 的孔为封闭区域。
- `src/road-planning.js`：贴地网格、捕捉、选择、模型占地校验、批量填充及保存信息。
- `src/road-planning-ui.js`：场景面板；视口 Grid/Snap 快捷按钮与面板同步。
- 新增依赖 `clipper-lib`，已随离线单文件打包，无运行时网络请求。

验证命令：

```sh
node test/road-parcels.test.mjs
bash test/withchrome.sh node test/road-planning-regression.mjs
bash test/withchrome.sh node test/road-endcap-regression.mjs
bash test/withchrome.sh node test/t-junction-regression.mjs
bash test/withchrome.sh node test/junction-regression.mjs
npm run build
npm run build:single
bash test/withchrome.sh node test/road-planning-offline.mjs
```

已覆盖默认关闭/独立开关、真实鼠标落点/拖点/Shift/预览一致、贴地网格、开放路网无地块、闭合网拆分、内岛/凹边界、实际视口选区、四种功能填充与替换、手动物体和锁定对象保留、单步撤销/重做、保存恢复、导出辅助层隐藏、改路后选区失效。

圆头、T 型与十字路口回归均复跑通过。本轮未重跑全部旧 UI/模板总门禁，不宣称总套件全绿。
