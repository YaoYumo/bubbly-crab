# 1.5.0 六项编辑增强与专项回归

## 实现

1. **曲线控制点**：道路选中即显点，拖动松手自动提交并保留道路 ID/元数据/跟拍关系；取消恢复原道路和原撤销栈。河流编辑显示可拾取点，保持 Y 拖 XZ，草稿保存一次撤销，不提前刻蚀。着色器圆点固定屏幕尺寸，拾取按屏幕像素，不添加大量小球。
2. **库外粗模**：注册受控基础几何组合资产，1–64 部件、尺寸/颜色/欧拉角白名单；禁止代码、URL、原型污染和任意字段。工程重建/修改 parts，以及“我的模型”静态存库与再次放置。不是真正任意网格生成器。
3. **本地 AI 范围**：同轮组合地形/河道/水面、道路、目录模型/粗模、人物车辆走位、新建机位及明确授权的天气/光影；保持直接应用、连续对话、单轮撤销、锁定/预算/取消/回滚。最多 12 主体、每路径 2–32 时间点；机位不覆盖已有剪辑。不增加任意脚本执行、外部资源或任意骨骼生成。
4. **家具与构件整组**：10 家具 + 18 构件默认/min/max 共 84 次构建；共享逐踏面楼梯、斜侧梁、连续扶手/立柱，折返高度/方向/平台、螺旋扇形修订。门窗真开口与家具玻璃去遮挡背板；摇椅弧形底轨/横梁连接；楼梯缩略图避免视角投影把坡道看成平板。另跑旧 parts：54 构件默认/min/max、楼板真洞、移动/删除/autoHole/撤销。
5. **人偶与动画**：收腰躯干、合并锥形四肢与圆滑关节、可见五官/发型、调整鞋与领圈。保留简化风格。Walk 两段 IK + 踝角抵消、固定髋部高度，不再用上下弹跳冒充走路；路径姿态由累计路程决定，seek/replay 不把瞬移计入步幅。Run/Sneak 去掉绝对值尖峰。不是全物理角色/复杂地形脚锁系统。
6. **车辆车头**：按资产真实前轴（车辆 +X、人偶 +Z）与时间匹配的路径切线对齐；修正左右转/倒走的前轴问题，保留非零自定义朝向。旧 AI 导入 faceOffset=0 按自动补偿，强制手动 0 使用 faceOffsetMode='manual'；导入缺省不再写 0。
