# AI 场景搭建：三批首版

2026-10-20。入口为 **Scene → AI 场景搭建**，与 Generate 的视频结果对照分开。目标是可检查的预演搭景，不是完整 DCC、导航系统、新模型生成器或自动成片系统。

## 1. 已落地的三批

## 2. 本地使用（不需要密钥）

1. 打开 **Scene → AI 场景搭建**。默认是「本地模板」，不联网；左侧选择内容，右侧检查独立预览。
2. 选择模板、应用方式和范围，点 **生成候选预览**，一次完成本地蓝图生成与候选准备，不必查看或操作 JSON。
3. 预览下方默认只显示新增／修改／删除数量。需要时展开 **查看改动明细**、**预览说明**；有警告时会显示提示数量，需展开检查并主动勾选接受后才能应用。
4. 点 **应用到场景** 并确认，完成后关闭窗口继续编辑；**Ctrl+Z** 一步撤销。任何设置变化都会禁用旧候选的应用，需重新生成。
5. **导入蓝图** 页签保留文件／JSON 粘贴；**AI 服务** 页签保留可选网关、请求恢复及计费确认，不会自动提交或应用。
6. 中心、种子、保留地形、工作包／蓝图／应用记录导出收在 **更多设置与导出**；**走位与机位（可选）** 单独折叠。

整体替换的授权勾选仅在选择替换模式时直接显示，不藏进高级设置。局部模式只授权打开窗口前选中的对象，并切到导入蓝图入口，不用本地模板偷偷添加整场内容。

默认界面不再平铺 API 按钮、JSON、对象 ID、三角数和长差异清单；保留所有权限、警告、源指纹和事务检查。窄屏改为单列，确认栏始终位于弹窗底部，预览和设置在中间滚动。

**局部修改**仅作用于打开弹窗前选定的库资产：`transform` 变换、`rebuild` 白名单参数局部重建、`remove` 删除。局部重建保留对象 ID、未请求修改的参数与走位；人物重建会重置局部姿态，部件选面也需复查。局部模式不通过模板向整个范围偷偷新增内容；请用工作包/API/手写操作蓝图，新增内容应明确切到添加模式。首版不编辑现有道路、植被 patch 或导入模型本体。

可在导出的合法蓝图中，用下列操作替换 `operations`，其中 `objectId` 必须来自当前授权选区，参数也必须来自该资产的真实 descriptor。**不要猜 ID、资产 key 或参数名，也不要手改源指纹来强行套用旧方案。**

```json
{"op":"rebuild","objectId":"selected-object-id","params":{"height":1.9}}
```

上例只适用于确实声明了 `height` 且范围包含 1.9 的资产。种子参数也同理：不是每个资产都有 `seed`。

## 3. 协议和空间边界

- [结构 JSON Schema](ai-scene.schema.json) 与工作包中嵌入的版本一致，单元测试检查同步。结构 Schema 之外，运行时还验证动态资产参数、权限、源指纹、空间和时间关系。
- 首版蓝图全局时长为 0.2–30 秒；增量/局部不得改变原全局时长，超出范围应先人工调整工程。走位从 0 秒开始并覆盖到全局末秒。
- 蓝图最多 512 KiB，显式或展开操作最多 180 个，候选几何预算 200 万三角；超过 200 条不同警告时拒绝发布候选，而不是隐藏后允许应用。
- 坐标单位米、Y 向上、朝向弧度。新增资产默认 `placement:"absolute"` 使用世界 Y；显式 `placement:"ground"` 用完整本地高度场采样地面，`pos[1]` 为高度偏移。地形粗采样仅供 AI 规划，不冒充精确地形。
- 造镇范围须为 128–384m 的正方形且边长为 64 的倍数；小范围/特定密度可能没有地块，此时明确拒绝，不把只有道路的空布局当作完成。boulevard 建议 384m 范围。
- 复用真实地块布局；建筑按实际世界包围盒保守适配。检查包含范围、保护物体、源物体重叠与坡面起伏；道路按线段与膨胀包围盒检测保护走廊，不只检查采样端点。
- 有锁定/保护路网时拒绝新增道路，因为原生道路系统会重算路口。不会把现有路网替换成一套新默认路网。
- 不自动侵蚀、改河道或找平整图。只有整体替换且明确取消保留地形时才允许 `terrain:"flat"`，其效果是关闭原地形显示，使用平面；不等于擦除高度场数据。
- 传统模板里的历史参数若不在当前声明目录中，仅配方适配层会逐项报告并保留其余合法参数，舍弃项采用声明默认值；原模板入口不改。**外部 AI/手动传入的非法参数直接拒绝**，不享有这种内部兼容处理。文本、颜色、明确声明的颜色列表和选择型参数均有严格限制。

候选窗口使用独立渲染器和基础灯光。原场景仅显示最多 1000 个线框包围盒，新道路显示中心线；不绘制完整地形、实际路口网格，机位轨迹也是示意，不是最终参考帧。最终灯光、材质与运动应在应用后主视图及参考包中检查。

空间检查是保守包围盒/地形采样，不是精确网格碰撞或完整约束求解器。未提供语义入口/连接锚点、任意关系 DSL 自动解算、沿现有道路自动补植被的通用求解、缺失资产自动建模、骨骼重定向、接触/脚滑修正。不能把一次候选无报错视为可拍摄或可通行保证。

## 4. 可选联网网关

默认不配置、不请求模型。开发服务器把相对路径 `/api/ai-scenes` 代理到 BFF；浏览器不直连供应商，也不使用模型密钥。`file://` 离线版只使用本地/手工工作流，不访问网关。

在服务端环境配置，然后重启网关；**不要把真实密钥提交到仓库或聊天**：

```bash
export AI_SCENE_ENDPOINT='https://YOUR-PROVIDER/v1/chat/completions'
export AI_SCENE_MODEL='YOUR-MODEL'
export AI_SCENE_KEY='SET-ON-SERVER-ONLY'
export AI_SCENE_GATEWAY_TOKEN='SET-A-SEPARATE-RANDOM-24-TO-256-CHARACTER-TOKEN'
npm run ai:gateway
# 另一个终端运行应用
npm run dev
```

上述值是占位说明，不能原样作为有效服务配置。Endpoint 必须是完整 HTTPS Chat Completions URL，不能在 URL 放凭证。默认启用 `response_format:{type:"json_object"}`；供应商不支持时可在服务端设置 `AI_SCENE_JSON_MODE=0`，但仍须返回合法蓝图。`AI_SCENE_ALLOW_LOCAL=1` 仅为 loopback HTTP 测试夹具准备，不是通用 HTTP 放行。

在弹窗检查能力，输入**与模型 Key 不同的网关访问口令**，再提交自然语言需求。网关口令只在当前弹窗内存保存；关闭/重开恢复查询时需重新输入，不写 localStorage、工作包或审计。只有 endpoint/key/model 和独立有效口令都配置后，网关才启用；提交及任务查询均受口令保护，外域请求也被拒绝。

提交前明确确认上传的目录、对象/参数摘要和范围。上游只得到文本工作包，不会上传模型二进制、画布截图或完整工程文件，但摘要可能含自定义名称、标牌文本、位置、道路、动作等敏感内容，请自行确认供应商数据政策。

### 任务/费用行为

- 20 秒单次浏览器请求超时、3 分钟本地轮询窗口、60 秒上游响应超时；没有自动重新提交模型请求。超时、网络中断、无效返回也可能已经计费。
- 每次提交先存请求 ID；回执丢失可按请求 ID 找回任务。服务端对同一个请求 ID 和相同完整内容防重提交，内容不一致返回 409；运行中请求也不会重复调用上游。
- 关闭弹窗或停止等待只停止本地轮询，**不取消供应商任务，也不承诺停止计费**。返回蓝图后仍须本地准备、检查、确认，不自动应用。
- 未确认提交的记录阻止盲目重提。确需忘记记录时，UI 明确要求确认重复计费风险。
- 网关并发上限 2、内存最多 100 个任务，结束任务约 1 小时保留；**重启丢失任务和幂等记录**。恢复查询不代表结果仍适用于源工程，过期指纹仍会拒绝应用。
- 这是带共享口令保护的单用户开发 BFF，不是生产多租户服务：没有账户级身份/所有权、持久化任务、供应商账单对账、完善用量配额。部署到生产需另行完成这些能力，不能把重启内存限额当作可靠计费上限。

本轮仅验收本地 HTTP OpenAI-compatible 夹具及 UI 协议模拟，**未调用真实模型、未验证任何供应商模型的搭景质量或计费行为**。旧版直连 API 的历史功能仍在原入口，不能将这里的新网关安全边界泛化为整个应用所有旧集成。

## 5. 事务、审计与参考包

准备/应用期间禁止参考导出、地形任务等互相覆盖；弹窗期间冻结源场景动画和交互，关闭后恢复。提交前再次校验源指纹，并重新编译候选防止候选文档被篡改；应用采用工程重新装配，保留稳定 ID，不保证保留原 JavaScript 对象实例。超出 12MB 原有撤销快照预算的工程会在破坏性应用前拒绝，避免承诺无法兑现的一步撤销。建议大工程先另存、拆分。

失败后恢复源工程、选择、视角、人物运行姿态及原 undo/redo 记录。准备期间检测到外部修改则拒绝候选，不能用回滚覆盖这类外部修改。候选释放只释放其自有几何/材质，不释放全局共享纹理。

可导出上次应用审计：来源（manual/local/API-adapter）、蓝图、对象/机位/地形/时长差异、警告、应用前后指纹。当前审计只在会话内存保存，可手工下载，**不是已经持久化到工程的完整版本历史**。

应用后原参考 ZIP 可附 `source/ai-scene-application.json`，含 `capturedFingerprint`、`sourceChangedSinceApply`。后续编辑或撤销会让标志为真；不能把“含应用记录”解释成“当前工程仍精确等于那次 AI 结果”。参考诊断仍按原工作台的保守规则执行。
