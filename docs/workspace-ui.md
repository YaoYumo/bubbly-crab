# 1.2.2 主题、模型库与水面修复

## 使用

- 浅色 / 深色 / 自定义三个圆点恢复到顶栏最左侧，不再藏在视口工具面板中。自定义支持背景色、面板色、强调色的实时预览、取消、恢复默认配色、保存并使用。设置以 `previz.theme.v1` 本地保存，与场景工程、材质、撤销分离。取消恢复原主题，切换内置主题移除自定义 CSS 变量。
- 模型分组改为紧凑下拉框，保留所有内置与自定义分组、搜索、导入、删除、移动及恢复能力。卡片有自己的垂直滚动区，组名栏不再悬浮遮挡卡片；场景物体列表独立滚动。收起模型库时物体列表恢复剩余高度。1568×842 实测可完整显示两行四张卡片，不含被截断的卡片；1024×720 短窗口仍能滚动。
- 新场景水面默认关闭；旧工程显式保存的 `water: true/false` 保持原样，缺失标记默认关闭，不删除或重写用户既有工程。
- 原水面表单读取初始化快照，切换只写入地形对象，下一次点击继续读取旧值，导致无法交替。改为实时 getter、同步开关状态 / 开关文字 / `aria-checked`，并在水面状态改变时刷新两个检查器。
- 水位输入不再隐式启用水面；自动水位和明确要求开启水面的示例调用仍保留原语义。生成海岛可设置推荐水位，但不覆盖用户的水面关闭选择。

## 验证

新增 `npm run test:workspace-ui`：开发版、断网单 HTML、桌面 CSP 前端预检均通过，报告在 `workspace-ui-evidence/`。覆盖主题位置、颜色预览、取消、保存 / 重载、切回内置主题清理变量、不改变工程；分组筛选、完整卡片数量、最后一张卡片可滚动触达、短窗口；水面默认、连续四次切换、水位不启用、撤销 / 重做、恢复明确水面设置、海岛生成及缺失旧标记。

通过：`npm run test:desktop`、`npm run test:radial-ui`、`npm run test:onboarding`、桌面浏览器预检及 `npm run all` / `npm run build:desktop`。模型库浏览器回归产出通过报告（含导入 / 移动 / 删除 / 恢复 / 工程携带 / 并发保护）；执行工具等待曾超时，随后确认进程已退出且完整报告已写入，不据此声称完整 `npm test` 通过。

均为 Linux Chromium / 模拟 IPC 检查，不是用户 Windows 的 GPU、原生磁盘或完整 UI 实机验收。Windows 构建、安装启动状态及下载链接以 `desktop-windows.md` 后续实际记录为准。
