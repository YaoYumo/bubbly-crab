## 2. 真实尺度体系（m）

- 车道 3.7；路侧带 2.25 = 缘石带 0.45（缘石高 0.15）+ 人行道 1.8（横缝 1.8 间距）；面层顶 0.15；
- 标线：边线 0.15、黄线 0.10（双黄中距 0.30）、虚线 0.10×3（9m 周期）、停止线 0.6、大陆式斑马线条宽 0.45 / 中距 1.05 / 长 2.4；缘石回转 R5；
- 环岛：环道 4.2 + 浅色铺装中心岛（图鉴式同心圆）+ 环行箭头 + 进口斑马线；
- 尽端路：圆头 R≈10.75（Ø21.5）、颈宽 8.5、环形挤出人行道、颈-环 R1.2 凹弧缘石过渡；
- 高速：2×2 车道 + 4m 中央带（防撞墙 0.85 高）+ 硬路肩 + 柱式 W 梁护栏。

## 4. 护栏（道路专属守卫）

`node test/roadkeep.mjs` → **ROADKEEP ALL PASS**，校验：

1. 道路组存在且 10 件名单与顺序不变；
2. 每件名称保留、builder 在位；
3. **真实尺度结构签名**（如 rdSideZ / rdCornerQuad / 锯缝 / 立砖收边 / 中央防撞墙 …），旧版风格化 builder 不含这些签名，回退即红；
4. **真实尺度参数默认值**（第 3 节表），误改即红；
5. 无 frozen 误标（道路组不应出现冻结标记）。

回退/改风格政策：如甲方要求改回旧版风格化道路或调整真实尺度默认值，须书面说明，并同步更新本说明第 2/3 节与 `test/roadkeep.mjs` 基线。

## 7. 后续协作流程（道路）

1. 甲方在导演台对道路件导出修补单（§4.3 格式）→ 乙方参数化烘焙进对应 builder（不开运行时补丁）；
2. 涉及真实尺度体系的修改（车道/路侧带/回转半径等）须先更新本说明第 2 节再动代码；
3. 每轮提交 = 主体 commit + `test/out` 截图 follow-up commit（惯例）；
4. 门禁基线以本说明第 5 节为锚，新增失败须当轮清零或经甲方书面豁免。
