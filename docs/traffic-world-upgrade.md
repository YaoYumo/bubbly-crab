# 1.9.0：匝道通行、交通随机性、路灯光斑与大地形

## 六项变化

1. **匝道口不再套用城市路口的逐车预约互斥**。主线直行不因匝道车辆预约而停车；汇入车辆只在目标车道确实没有安全间隙或行人占用汇入通道时让行，不能承诺在真实拥堵下永不减速。保留普通受控城市路口的红黄绿停行规则。紧凑汇入口补全主线车道分界与外侧导流线，按实际固定车道宽定位，扣除虚拟车行道中心内的路肩偏移；不在高速口添加斑马线／停止线，也不打开中央带。
2. **地形边界车辆全速进入、直接离场**。构图时按道路起终点距地形边缘约 2m 判定边界；车辆从该入口出生时使用道路限速，入口附近保持巡航。不因另一端入口暂时堵塞而排队停在出口：先不可见离场，有足够入口安全距离再全速进入。前车、真实信号和汇入冲突仍优先于全速要求。非边界自由端仍采用本地重新入场逻辑。
3. **随机但可复现**。修复旧线性哈希令相邻编号位置近似相同的问题，使用非线性混合种子；车道分配打散，位置、巡航速度、跟车间距、车身尺寸／颜色、行人横向偏移与步态相位各自变化。不会随机逆行、跨车道游走或高速生成人群。工程保存的种子与固定步进保证时间回退／导出可重现。
4. **附属路灯使用共享预烘焙衰减光斑**。仍沿用原路灯开关与间距设置，夜间自动显示，白天隐藏；每条路一个额外批次，共用一张 64×64 RGBA 纹理，贴合道路纵坡，不新增逐灯实时光源或阴影。它是轻量照明近似，**不是带遮挡／全局光照的场景烘焙，也不会照亮行人或车身**；不能代替离线光追 lightmap。相比逐灯实时照明更轻，不代表比旧版纯自发光、没有路面照明时更快。
5. **中间视窗内的性能浮层**。点击顶栏「性能」时启用，关闭诊断弹窗后仍留在视窗左上角；浮层有详情与关闭按钮。关闭光影进入节能模式时也显示。提供滚动帧率、帧间隔、可用时的 GPU 计时、draw calls、三角面、JS 堆、几何／纹理／实例数与场景资源显存估算。500ms 更新显示，资源遍历最多每 2 秒一次（手动打开时立即刷新）。浏览器不能可靠读取整机总内存、总显存或进程独占显存，因此明确显示不可读；估算不含驱动、渲染目标及其他程序。HTML 浮层不进入 PNG／视频。
6. **地形边长支持 40–4096m**。在地形面板输入尺寸，导入高度图、工程保存／载入、河道恢复及本地对话的地形尺寸也支持。尺寸与 33–513 网格密度独立：增大尺寸不会偷偷增加顶点数，但每格实际覆盖面积增大、细节下降。编辑视野的远裁剪与缩放范围自适应大地形，天空保持可见；机位取景仍尊重机位自身裁剪参数。一般物体／道路 AI 指令的既有安全坐标范围与河道对话单次操作预算没有一并放开。

## 升级与使用

旧工程重新打开即可重建派生交通和路口标线，不需要为了本次规则变化重画整个螺旋。自动交通与道路附属路灯仍默认关闭；先选道路，在对应控件启用。实际运行数量可能因安全出生空间不足而小于设置预算，离场等待重新入场的实例不会显示。

本版继续是预视工具，不是工程级交通仿真：不包含目的地导航、动态超车变道、工程认证的完整加减速车道或所有地区的交通法规。普通灯控、主线优先及安全间距均为简化规则。灯光光斑不会实时计算车辆／建筑遮挡。
