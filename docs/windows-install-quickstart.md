# PREVIZ LAB Windows 安装包使用说明

此文件是随构建附带的通用说明。具体版本以安装器文件名为准；最新下载、哈希和检查记录请查看仓库 `docs/desktop-windows.md`，不要把历史说明里的链接当作本包版本。

## 安装／升级

1. 升级前将重要工程另存 `.previz` 并备份，退出旧版。
2. 在 ZIP 的 `src-tauri/target/release/bundle/nsis/` 下双击 `PREVIZ LAB_*_x64-setup.exe`。`src-tauri/target/release/previz-lab.exe` 是应用程序，不是安装器。
3. Windows x64、当前用户安装。已有 WebView2 Runtime 时不下载完整运行时；缺少时需要联网获取微软运行环境。应用不含 Node、AI模型或模型服务，不会自动运行模型。
4. 这是未签名预检版。可能出现未知发布者／SmartScreen提示，不要因此关闭安全软件。包内 `.shots/desktop-artifacts.json` 记录实际安装器字节数及 SHA256，可用 PowerShell `Get-FileHash -Algorithm SHA256 '安装器路径'` 核对。
5. 先测试工程打开／另存、PNG和短视频，再用于重要项目。Windows runner 的安装／窗口检查不等于你电脑上的剪辑交互、原生文件保存和GPU导出全面验收。

## 时间轴镜头剪辑

- 建好多个机位后，点击底部「顺序拼接」；或「+ 当前机位」追加，再按播放检查切镜头。
- 默认只显示镜头片段；「关键帧」按钮按需展开独立行，不再把全场景关键帧叠到片段上。
- 拖动底部上边界可调整轨道高度；「+／−／适配」控制时间轴缩放，放大后在轨道区横向滚动。
- 点击或拖动时间标尺定位；单击片段选中并定位，拖中间移动，拖左右宽手柄裁剪。选中片段后在标尺上找到切点，再按「分割」。
- 「起／止／源入」输入秒数可精确调整。剪辑支持撤销／重做，并随工程保存。
- 关闭「剪辑预览」恢复活动单机位。源机位关键帧／曲线仍按单机位方式编辑；参考包也需关闭剪辑预览后按单机位生成。
- 当前为单视频轨硬切，没有音轨、叠化或变速。含剪辑的工程请使用1.1.0及以后，不要用旧版重新保存。

详细语义及限制见仓库 `docs/camera-edit.md`。

## 1.2.0 新手指引与模型库

- 首次启动显示新手指引，可跳过；以后从「操作 · 右键 → 工具 / 工程 → 新手指引」重新打开，也可按 `?` 进入帮助后启动。
- 导览只讲解，不生成、覆盖或删除场景；结束后返回原页面与视角。
- 顶栏只有五页面、性能、桌面检查。物体变换、机位与工程操作移入右键饼菜单及工具面板；右拖仍是平移。
- 统一模型缩略图；用户模型可导入至分组、移动及删除。内置模型移除可恢复。库分组保存在当前应用本地；已放入场景的模型随 `.previz` 工程包携带。
- 已包含新增灰模 / 木构宝塔以及中式古建斜边楼梯。本包不包含 AI 权重，不会自动调用模型。
