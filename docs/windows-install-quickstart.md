# PREVIZ LAB Windows 安装包使用说明

此文件是随构建附带的通用说明。具体版本以安装器文件名为准；最新下载、哈希和检查记录请查看仓库 `docs/desktop-windows.md`，不要把历史说明里的链接当作本包版本。

## 安装／升级

1. 升级前将重要工程另存 `.previz` 并备份，退出旧版。
2. 在 ZIP 的 `src-tauri/target/release/bundle/nsis/` 下双击 `PREVIZ LAB_*_x64-setup.exe`。`src-tauri/target/release/previz-lab.exe` 是应用程序，不是安装器。
3. Windows x64、当前用户安装。已有 WebView2 Runtime 时不下载完整运行时；缺少时需要联网获取微软运行环境。应用不含 Node 或 AI 权重。1.3.0 附带本地推理引擎，桌面“一句话生成”发送时自动加载安装目录 models 内的 GGUF，无需手动启动服务。
4. 这是未签名预检版。可能出现未知发布者／SmartScreen提示，不要因此关闭安全软件。包内 `.shots/desktop-artifacts.json` 记录实际安装器字节数及 SHA256，可用 PowerShell `Get-FileHash -Algorithm SHA256 '安装器路径'` 核对。
5. 先测试工程打开／另存、PNG和短视频，再用于重要项目。Windows runner 的安装／窗口检查不等于你电脑上的剪辑交互、原生文件保存和GPU导出全面验收。

## 时间轴镜头剪辑

- 建好多个机位后，点击底部「顺序拼接」；或「+ 当前机位」追加，再按播放检查切镜头。
- 默认只显示镜头片段；「关键帧」按钮按需展开独立行，不再把全场景关键帧叠到片段上。
- 拖动底部上边界可调整轨道高度；「+／−／适配」控制时间轴缩放，放大后在轨道区横向滚动。
- 点击或拖动时间标尺定位；单击片段选中并定位，拖中间移动，拖左右宽手柄裁剪。选中片段后在标尺上找到切点，再按「分割」。
- 「起／止／源入」输入秒数可精确调整。剪辑支持撤销／重做，并随工程保存。
- 关闭「剪辑预览」恢复活动单机位。源机位关键帧／曲线仍按单机位方式编辑；参考包也需关闭剪辑预览后按单机位生成。
- 当前为单视频轨硬切，没有音轨、叠化或变速。含剪辑的工程请使用1.1.0及以后，不要用旧版重新保存。

详细语义及限制见仓库 `docs/camera-edit.md`。

## 1.2.0 新手指引与模型库

- 首次启动显示新手指引，可跳过；以后从「操作 · 右键 → 工具 / 工程 → 新手指引」重新打开，也可按 `?` 进入帮助后启动。
- 导览只讲解，不生成、覆盖或删除场景；结束后返回原页面与视角。
- 顶栏只有五页面、性能、桌面检查。物体变换、机位与工程操作移入右键饼菜单及工具面板；右拖仍是平移。
- 统一模型缩略图；用户模型可导入至分组、移动及删除。内置模型移除可恢复。库分组保存在当前应用本地；已放入场景的模型随 `.previz` 工程包携带。
- 已包含新增灰模 / 木构宝塔以及中式古建斜边楼梯。本包不包含 AI 权重，不会自动调用模型。

## 1.2.1 右键菜单修复

- 修复视口饼菜单与 WebView 默认右键菜单叠加的问题，保留右拖平移、键盘操作及输入框正常右键菜单。
- 保留 1.2.0 新手指引、模型库与全部既有工程功能。升级前另存备份工程并退出旧版，再运行 1.2.1 安装器；不需要清理本地工程或缓存。
- 此次仅重新构建修复版，不包含签名或浏览器信誉变更。不关闭安全设置、不配置排除项。

## 1.2.2 主题、模型库与水面修复

- 三个主题圆点恢复顶栏左侧；自定义主题可调整背景、面板与强调色，实时预览、取消或保存，并在此应用本地记住。
- 模型分组改为紧凑下拉选择，卡片独立滚动，不再被分组栏遮住；物体列表仍可独立滚动。
- 新场景水面默认关闭；连续开关可正确交替，调整水位不再偷偷打开水面。生成地形保留关闭状态，已有工程明确保存的水面设置继续恢复。

## 1.2.3 模型拖入场景修复

- 恢复从模型缩略图 / 名称拖入视口：内置模型与用户导入模型均使用鼠标落点放置，支持撤销 / 重做，保留点击放置。
- 删除 / 移动分组等卡片控件不会被当成模型拖拽来源；取消或拖到视口之外不放置。
- 保留 1.2.2 主题位置 / 自定义配色、紧凑分组与独立滚动、水面默认关闭等修复。

## 1.3.0 本地模型对话搭景

- 推荐 RTX 4070 Ti 12GB 使用 Qwen2.5-7B-Instruct Q4_K_M GGUF；不随安装包下载权重。
- 安装后打开“一句话生成”→“打开模型文件夹”，把 GGUF 放到这里，再刷新。这个 models 位于安装后的应用 EXE 旁，不是安装器所在的下载目录。
- 直接用中文描述场景或继续对话修改，后台校验后直接应用，每轮可撤销；不需要工作包、蓝图、候选预览、端口或 API key。
- 组合现有素材，不生成新的3D网格；地形、灯光、水面、时间轴不在本入口范围内。不支持或验证失败会明确提示，不生成默认小镇替代。
- 模型首次加载需等待；可以停止。显存或 Vulkan 驱动有问题可在模型设置切换 CPU。真实模型速度与效果需在本机验证。

详细说明见仓库 docs/desktop-local-ai.md。

## 1.3.1 网络拦截组件兼容性修订

- 本地模型端口分配、健康检查和推理通信移入独立、随包的阻塞 I/O 辅助进程，主程序不再为此创建 Tokio 异步网络套接字。
- 针对用户报告的 ASProxy64.dll 访问冲突隔离故障路径，不要求关闭或卸载代理/VPN，也不修改系统网络设置。
- 可覆盖安装到原目录，模型不用重下或改名。CI 会检查安装后的辅助进程、中文 JSON 回传、超时、重定向拒绝和用户模型目录重装保留；不代表已验证用户机器的 DLL 兼容性。

## 1.4.0 地形 / 河道 / 路网对话

- 可直接说“生成丘陵，水面保持关闭”“局部抬高4米，并让原有建筑贴地”“修一条中轴道路并加宽”“造一条河，不开全局水面”。仍然是发送后直接搭建、整轮撤销，不需要蓝图或候选预览。
- “30座中式民居，中轴对称路网，不要河流”可使用批量阵列；仍受每轮200万候选三角预算限制，不能承诺任意30个高细节大殿都同轮生成。
- 覆盖已有起伏地形/手绘地表/导入高度会确认；河道编辑/删除只改河面和再刻蚀，不自动填旧沟槽。水面默认关闭，锁定对象下的地形不允许隐式改变。
- 本包仍不含权重，原目录两个GGUF不动。模拟IPC回归不是4070Ti上真实Qwen推理质量的证明，安装后应先用简单场景检查。详细能力/边界见随包 `docs/desktop-local-ai.md`。
