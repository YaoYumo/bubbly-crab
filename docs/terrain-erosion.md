## 使用路径

1. **Scene → 地形 → 基础**：生成或设置地形；高度 PNG 在 **导入**，颜色贴图在 **材质**。
2. **侵蚀**：选择自然坡地、热力风化、雨水沟谷、沉积整理、岩质风化或脊状沟壑预设。设置强度、最大升降、种子和作用范围；高级参数默认收起。
3. 点 **计算侵蚀预览**。计算期间可从顶部任务条取消；原始高度、撤销栈不变。
4. 切换 **结果 / 原始 / 升降 / 侵蚀 / 沉积 / 径流 / 范围** 查看。升降图红色为削低、黄色为抬高；范围白色可作用、黑色受保护，中灰为过渡。
5. 顶部 **应用结果** 才写入高度并执行既有自动底材、模型贴地和道路联动；一次 Ctrl+Z 撤回，Ctrl+Y 重做。**放弃预览 / Esc** 不改变原始高度。

调整参数会丢弃旧预览，下一次计算仍从原高度开始，不会暗中累计。离开 Scene 页会取消尚在进行的侵蚀计算、放弃未应用预览。保存工程不包含临时预览；应用后的高度及侵蚀设置会保存。

## 实现内容与明确语义

### 热力坡面搬移

- 按世界米格距及稳定坡角判断超限坡面，把高处材料向相邻低处搬移，而不是简单模糊。
- 分轮同步累加通量；每格的流出量、流入容量均受升降上限约束。
- 轮次、稳定坡角、搬移速率、整体强度可调；四周各一圈网格固定。

### 水力侵蚀与沉积

- 固定种子的雨滴模型：双线性坡面采样、惯性下坡、速度 / 水量、携沙容量、侵蚀、落沙及蒸发。
- 侵蚀使用有限网格笔刷；世界米半径换算到网格，支持降低地形，也支持沉积抬高，不沿用旧河床刻蚀的 lower-only 限制。
- 遇保护区、边界或升高上限，无法落地的携沙沿该雨滴的侵蚀轨迹回存，避免把未沉积材料悄悄删掉。回存体积、极小残留和 Float32 舍入体积单列。
- “侵蚀 / 沉积”图是累计搬运量，允许同一位置多次搬入搬出；不是最终高差。“径流”图是雨滴经过量，仅作相对强弱显示，不是 m³/s 或汇水分析。

### 沉积整理

- 综合流程：热力 → 水力（含落沙）→ 对已搬入的松散材料做坡脚整理。
- 仅沉积流程：以用户指定厚度标记可搬移松散表层，沿低坡角搬移；不凭空给洼地加土。厚度为 0 时不改变地形。
- 有独立的整理速率；综合 / 水力流程的后整理以 12° 为目标，单独沉积模式采用面板稳定坡角。

### 河道 / 区域联动及保护

- **全图**、**矩形局部**、**河道及岸带**、**河道岸带以外**共用一个静态 XZ 遮罩，可选择某条或全部有效的已保存河道。
- 河道影响范围 = 河宽 / 2 + 岸坡宽 + 岸外影响宽；外圈平滑衰减。矩形边缘有约一格过渡。遮罩同时控制速率和最大升降幅度。
- **保护全部已保存河床**：所有有效保存路径的河宽以内顶点不变，岸坡做柔和过渡；与当前选中哪条河道独立。
- **保护模型 / 道路投影包围盒**：保守保护每个模型的世界 XZ AABB 及一格过渡，包含悬空模型，不包含 `fx` / `vegetation_patch`。曲路和旋转建筑可能保护较大的矩形；不是精确道路断面保护。
- 没有有效关联河道、所选河道失效、区域在地形外或全部受保护时明确报错，不悄悄切换成全图。
- 不修改河道控制点、水位或已保存河面，也不自动重刻河床；不自动识别 / 汇流 / 生成河网。

### 岩质 / 脊状风格

- **岩质风化**：随原始世界高度周期变化的抗蚀层，搭配较大坡角、较少热力搬移；岩层间距可调。
- **脊状沟壑**：凸脊曲率增强抗蚀，搭配窄侵蚀半径、较低惯性 / 沉积和较陡稳定坡角，尽量保留脊线与细沟。
- 预设是本项目算法的参数组合，不是 World Creator 专有算法复刻，也不是给已有低密度网格增加真实分辨率。

## 地形 UI 整理

六组子页只显示当前一组，两个既有检查器入口共享组选择：

| 分组 | 内容 |
| --- | --- |
| 基础 | 地形生成、网格、尺寸、全局水面、自然素材提示 |
| 雕刻 | 原地形笔刷、植被笔刷、道路画笔 / 规划 |
| 侵蚀 | 六个预设、常用参数、区域保护、默认收起的高级参数与说明 |

水面、自然素材提示、植被和道路组默认折叠；折叠状态与当前子页在本次应用会话中保留，重绘 / 撤销不会全部展开。子页支持方向键 / Home / End，分组标题支持 Enter / 空格。忙碌 / 待应用时，旧工具参数禁用；所有子页顶部保留取消任务或应用 / 放弃按钮。

## 数据一致性 / 资源 / 互斥

- 在副本中计算，提交前比对源网格、完整高度 / 手绘权重、分辨率、尺寸、夸张、启用状态、底材 / 水面设置、保存河道以及模型变换 / 参数；发现并发变化拒绝结果。
- epoch 使取消、清空、载入、撤销 / 重做后的旧任务不能重新提交。外部地形 / 材质 / 物体变化使已生成的预览失效。
- 应用前也用 Float32 记录撤销源，即使它来自旧的厘米量化存档路径，撤销不会把原始生成高度量化到厘米。
- 临时网格单独持有、替换显示；不改原高度和道路。取消释放临时 geometry / 诊断 material，不释放共享地形材质。选择性 Bloom 把它作为遮挡物，不作为发光对象。
- 地形计算或侵蚀预览期间拒绝播放 / 机位预览 / 视频和 PNG 导出。应用或放弃后恢复导出。
- 仍使用主线程协作分片，不是 Worker，不承诺单片硬性 4ms。513 网格 / 大雨滴数量会更慢；建议先低轮次预览，再增加数量。

## 仍然存在的边界

- 默认 97×97 / 160m 格距约 1.67m，513 时约 0.31m；定位中尺度坡面、沟谷和堆积，不等于 World Creator 高分辨率细纹理。
- 是近似高度场材料搬运，不计算真实河流水动力、汇水区、流量或河口出沙。径流图不是自动河网。
- 预览沿用原始材质属性，不预先移动模型 / 道路；应用后重新计算自动底材。应用触发的既有地基 / 道路整形仍可能调整局部地面，跨河桥梁仍建议固定标高。
- 修改 / 删除旧手绘河道不回填旧河床；颜色贴图 / PNG 的既有限制仍按上一阶段说明执行。
