# 第三阶段：编辑后诊断与组合件联动首版

2026-10-21。第二阶段的受控 AI 关系继续保留，新增按需场景检查、当前 AI 关系记录随工程保存、静态组合件稳定 ID 挂接与编辑完成后的可选联动。**不包含第四阶段的多步骤行为、自动导航或避障。** 未安装或运行真实 AI 模型。

## 1. 使用入口

**Scene → 右侧检查器顶部 → 场景检查 / 部件联动**，默认折叠。

- **运行场景检查**：只读检查，列出当前提示；点击“定位”可选择并聚焦对象，不移动对象。
- **同步选中组合**：选宿主时同步其下游挂接部件；选部件时同步自身及下游。重新计算、确认后才修改，可一步撤销。
- **同步全部挂接**：整批重新计算；遇到无效引用、锁定漂移部件、保护碰撞、越界或预算问题，整批拒绝，不部分提交。
- **导出检查摘要**：导出 JSON，包含检查覆盖范围、过期、预算完整性和最多 200 项提示。过期报告可导出，但不能当成当前状态。
- **清除 AI 关系记录**：只清除诊断规则，不移动或删除场景对象，可撤销。它不清除组合件挂接。

编辑、删除、地形变化、时间变化等会将旧报告标为 **已过期**；不会在每次输入或每帧自动扫描全场。没有报告时也不显示“检查通过”。

### 自己建立一个挂接

1. 选择要作为部件的静态库资产。
2. 展开“建立 / 管理挂接”，选择宿主；锁定对象也可作只读宿主。
3. 点击“按当前位置建立挂接”，确认关闭部件地形跟随。位置、朝向和缩放不改变，只记录当前局部关系。
4. 默认**不开启**自动联动。可手动同步，或明确勾选“宿主编辑完成后联动”。
5. 若不再需要关系，选择部件点击“解除选中挂接”；解绑不挪动物体，可撤销。

支持库建筑与静态道具；人物、FX、道路、导入模型、活动走位、非 Y 轴旋转或宿主非等比缩放会拒绝，不自动近似。部件可保留自己的非等比外形，但宿主必须正的等比缩放。

## 2. 新配方组合件与旧工程

通过当前版本的示例场景／一句话配方新生成的两种批准组合：

- `cyber-frontage`：沿街商铺 + 霓虹招牌；
- `river-frontage`：中式铺面 + 暖窗格栅。

会在整组创建完成后建立真实宿主 ID 引用，保持原始位置，默认 `follow:false`。保存后可恢复，不再仅依赖 `sceneKit.instance` 名称推断。

已知组合保留初始局部偏移；宿主的 `depth`／`d` 发生变化时，前向挂点按深度差的一半更新，并考虑宿主等比缩放。保留初始深度和偏移，避免非 1 倍缩放的原始布景一加载就跳位。侧向偏移不因为宿主旋转重新套一次旧布局公式。

**不重塑招牌文字、格栅分格、窗宽或楼层**。改宽高不等于自动重新设计立面；这里只维护挂点、朝向和根缩放。

旧工程如果只有 `sceneKit` 来源标记，不会在载入时猜宿主、移动部件或自动迁移。检查会报告 `unbound-kit`，可由用户按当前位置手动建立局部挂接；这种手动挂接不自动恢复已知配方的语义深度锚点。

复制宿主或部件时，新副本去掉挂接及配方角色标记，作为独立物体，避免副本突然吸回原宿主。原件的记录不变。删除宿主不会级联删除部件；下次检查报告引用缺失，等待用户解绑、重绑或删除。

## 3. 自动联动的明确边界

开启后，仅在以下明确编辑完成点更新已启用的下游部件：

- Gizmo 拖拽结束，而不是拖拽每帧；
- 物体检查器的位置／旋转／缩放数值更改；
- 单个宿主参数重建完成。

宿主编辑与自动部件更新共用原来的撤销步骤。用户直接移动部件不会把该部件立即吸回宿主，只联动它的下游；检查仍可提示它偏离原挂接关系。

**载入、撤销／重做、AI 应用、批量配方、播放和导出不会由对象事件监听器触发自动修复。** 特别是 AI 候选只允许修改已授权内容，不能在加载候选时额外移动未授权部件。批量精度切换、地形重整、其他脚本变换或未接入的工具可使挂接漂移，应检查后手动同步。

若自动同步遇到锁定部件、其他锁定对象碰撞、循环、越界、任务互斥或预算问题，保留宿主本次编辑，但不移动这一批部件，并提示原因。宿主编辑仍可撤销；不会为了强行跟随而解锁部件、移动保护对象或悄悄部分提交。

这是**静态编辑完成后的联动**，不是 Three.js 持续父子 rig、骨骼约束、人物接触或播放期间的自动跟随。

## 4. 诊断覆盖范围

| 检查 | 含义与限制 |
| --- | --- |
| 挂接状态 | 稳定 ID、缺失宿主、循环、锁定、地形跟随冲突、位置／朝向／缩放漂移、格式／支持范围 |
| 保存的 AI 关系 | offset、face、distance、keep-out 按当前对象重新检查；带活动走位、非支持参考或无有效几何会标为未检查 |
| 可能重叠 | 可见、静态、非 FX 的库资产世界 AABB；排除部分地面／道路类及直接宿主部件对。**不包含所有导入模型、道路、地形和隐藏几何** |
| 路径风险 | 活动路径相邻关键点的直线段与静态库障碍 AABB；时间、维度、有限数和点数检查。不是实际曲线完整扫掠、角色体积碰撞、行人协调或导航 |

AABB 可能把相邻屋檐、空心结构或上下错层误判为风险；不会据此自动移动对象。路径风险只检查关键点折线，可能漏掉曲线偏出的部分，不能作为“无碰撞”证明。原有道路专业采样检查与两配方的生成前检查继续独立保留，本面板不冒充所有诊断的总验收。

检查摘要明确列出静态候选数、排除静态重叠检查的对象数和覆盖说明。“0 项提示”只针对该覆盖范围，不是全场几何／电影构图／工程规范合格判定。

## 5. 两类持久数据，不要混淆

### A. 组合件挂接

保存在部件的 `params.sceneAttachment`：

```json
{
  "version": 1,
  "hostId": "stable-host-id",
  "kind": "local",
  "offset": [0, 2, 4],
  "yawOffset": 0,
  "relativeScale": [1, 1, 1],
  "follow": false
}
```

已知组合另有 `depthBase`，用于按深度差更新挂点。只接受固定字段、有限值和有界数组，不执行代码，不重新加载模型资源。挂接本身不会进入 AI 可写资产参数白名单；普通 AI 参数 patch 不能任意写此元数据。

### B. AI 当前关系诊断记录

保存在工程可选根字段 `layoutRelations:{version:1,rules:[...]}`，结构同第二阶段受控协议。

- 通过 AI／手写蓝图应用关系后自动保留当前规则；与工作包指纹、候选确认、工程保存及撤销兼容。
- 后续 offset／face 覆盖同类型、同主体的旧槽位；distance／keep-out 覆盖同类型、同有序对象对的旧槽位，避免新意图与旧意图互相矛盾。其它规则保留，总计最多 128 条，超限拒绝，不静默截断。
- 删除对象会留下可诊断的缺失引用；替换全场景会清除旧记录再加入本次规则。
- 这些是当前诊断条件，不是完整 AI 版本树。历史应用审计仍按原机制单独存在。
- **不会自动变成组合件挂接**。要让某个对象随宿主联动，需用户另行建立挂接并明确开启；AI 相对偏移通常是世界坐标，而挂接可能包含宿主等比缩放，两者语义不同。

工程保存／JSON 往返已验，当前 `.previz` 包沿用保存整个 `project.json` 的机制。旧程序不认识这些行为，打开后重新保存可能丢失关系功能，应使用当前版本。离线单文件也包含这些编辑能力，不连接模型服务。

## 6. 事务、安全与预算

- 播放、导出、参考采集、AI 准备、地形操作／侵蚀预览、道路／植被编辑、Gizmo 拖拽等互斥。先结束任务再操作。
- 默认不联动。手动同步需确认并重新计算，不信任旧报告作为修复授权。
- 只改合格部件的根变换，不移动宿主或外部锁定对象。已锁定但漂移的部件拒绝同步；宿主锁定仍可作只读参考。
- 在提交前用不改源几何的矩阵预测世界包围盒，检查 ±600m 世界范围、其它锁定对象碰撞（允许与自己的宿主／祖先搭接）。不复制带循环 App 引用的 `userData`，不销毁共享几何／材质。
- 变换、元数据、地形跟随开关和撤销栈在失败时恢复。测试注入“第二个部件更新失败”和“撤销记录失败”，验证不留下半批结果。
- 单次维护最多 2000 对象、256 挂接；同步的预测几何总预算 25000 网格／实例，对未缓存包围盒的顶点采样最多 300 万。保护检查最多 20000 对，超限拒绝提交。
- 通用重叠与折线扫掠各最多 20000 次，路径最多 256 关键点。达到扫描预算会标记 `complete:false`，不能算完整检查；问题列表最多 200 项并带 `issuesCapped`。
- 修复操作沿用 12MB 撤销快照保护，超过时拒绝并建议拆分／保存工程。
