### 地形编辑

- 笔刷优先显示；真实地形射线拾取，不再以零高度平面代替山坡落点。描边按高度场贴合起伏。

- 平滑读取不可变源高度，以更宽的邻域和积分图处理陡坡；坡度缓和以落笔位置为锚点，逐步收敛到目标角度，不承诺一次操作让整座山达到工程纵坡。
- 每笔一个撤销；Esc、pointercancel、失去捕获可取消本笔，不留空撤销；空白笔画不创建历史。材质单独涂绘不触发地基找平或道路重建。
- 网格扩展到 257、513，原有档位保留；细化用双线性重采样保留高度和六层材质权重。160m 地形在 257 / 513 时格距约 0.63m / 0.31m。超细网格成本更高，不是自适应地块流式地形。
- 六种混合程序化表面：草地、泥土、碎石、岩石、沙地、积雪；世界空间纹理颗粒和不同粗糙度，不依赖外部贴图。不是新增任意图片贴图导入工具。
- 高度及材质权重随 JSON / `.previz` 保存；极端高度超出原厘米 Int16 范围时增加 Float32 数据，避免默默截断。

### 已补齐：一键生成与自动地貌材质

- 修复生成按钮引用不存在的表单状态的问题；实际 UI 验证不选类型不修改场景 / 不留空撤销，选择类型、起伏幅度、随机种子后可一键执行。生成参数保存在地形中，不再被面板重绘清空。

- 生成替换全图高度并启用自动底材，保留手绘覆盖位置；海岛开启水面，其他类型沿用当前水面设置。已有道路及植被继续走地形变化联动。生成前退出活动绘制，支持一次撤销 / 重做。
- 「自动地貌底材」独立控制开关、裸岩坡度、坡度过渡、雪线标高、雪线过渡与岸带宽度。坡度使用实际米制格距与显示高度比例，雪线按世界标高而不是全图最高点归一化；小土丘不会因“相对最高”而自动积雪。
- 草 / 土 / 碎石 / 岩 / 沙 / 雪六材质按权重混合颜色、程序颗粒及粗糙度。草地 / 森林保留各自植被色，陡坡露岩；沙漠以沙为主，沙漠 / 焦土 / 异星不自动降雪，雪原自带低地积雪。
- 岸带基于实际水下网格的近似水平距离，并按坡度抑制峭壁沙滩；不是只凭海拔把整张低地涂成沙。改变水面开关 / 水位、山形 / 高度夸张、网格密度或规则会重算底材；不逐帧重算。
- 自动底材与手绘覆盖各自独立，手绘可以部分混合或完全覆盖；修改山形、生成新地形、重算底材不覆盖手绘。Shift 擦除手绘后露出当前自动底材，手绘纯材质笔画不重算全图自动分类或道路几何。

### 道路

- 新绘制道路随地形：按整条路径和完整横断面采样，不只采控制点或中心线；将长三角形细分后变形，保留横断面、路缘、标线及圆头。
- 「物体 → 道路参数」可以切换「随地形」与「固定标高」，设置起点标高（整条设计线相对高差保留）。固定标高适用于高架；不会自动挖山，地形高于设计线时需压低地形或提高道路。
- 地形笔画提交后重建道路及路口网络，保留道路 ID、名字、材质策略和机位跟踪引用；随地形路口有共享平整核心和渐变接近段。

- 固定标高道路进入改线后，拖点、延长控制线仍保留设计高度，不被重新吸落地面。

### 桥墩、植被与填土

- 高于地面的间隙超过「架空阈值」时生成柱身、埋入式柱脚及横向承托；默认阈值 1.8m、间距 12m，可关闭或调整。小间隙可使用路基填充。
- 全体积三维保守包围盒检查下层道路、建筑及其它物体，承托也参与碰撞；同一道路的上下层自交另做三角形检查，避免穿进自身的下层路面；其它已生成桥墩也作为障碍。
- 冲突时尝试沿道路前后移位；所有候选均受阻则跳过并在检查器报告「受阻未放置」。不会强行落柱、移动建筑或删除下层道路。
- 自动清理与道路 / 桥墩相交的库植物和笔刷实例，保留无相交植被（包括桥下高度足够的矮植物）。此自动清理不同于植被笔刷的手工擦除规则，会清理手工植物。导入模型默认作为普通障碍物，可在物体面板明确标记「作为植被清理」。
- 选择道路可一键填路基，也可用「路基填充」笔刷只抬高局部；限定道路走廊、软化肩部，填土体积避让下层道路和建筑，不全场抬地。
- 地形、道路参数、填土及衍生植物清理纳入同一撤销 / 保存；支撑由设计线和地形确定性重建，不重复存整套桥墩几何。
- **边界**：碰撞偏保守，可能放弃实际可用的狭窄空间；受阻不代表自动设计了替代大跨结构。未提供荷载、跨度、净空法规、抗震或地质验算，不能当作土木工程设计工具。复杂场景增量重建和分块 LOD 仍属于第 6 项。

## 已实现首版：5. 物理天空 + 灯具真实照明（窗户、泛光后续）

### 天空与相机

- 入口：Scene → 光影 →「照明模式」选「物理天空」。旧工程缺少模式字段时仍使用「经典氛围」，不把已有月光 / 棚拍预设机械解释为真实太阳；旧模板与 `applyPreset` API 继续使用经典模式。
- Three.js `Sky` 解析大气散射，太阳高度 / 方位、大气浑浊度、瑞利 / 米氏散射、统一天空 / 直射增益。提供晴天、暖日落、蓝调、无月夜起点；不新增体积云、星空或月光模型。
- 可选日期、当地小时、经纬度、UTC 时差与北向旋转；新加坡 / 北京示例需主动选择。太阳位置为几何近似，不联网定位，不自动查询夏令时，也不随播放时间自动推进天文时间。
- 背景与 PMREM 环境反射共用大气参数和太阳方向；太阳盘仅在背景显示，反射烘焙排除太阳盘，避免与有阴影的直射重复。物理模式关闭旧 ambient / hemisphere / fill / rim 叠光。
- 参数变化合并后按需烘焙 256 档 PMREM，不逐帧生成；曝光、白平衡、反射强度、相机运动不触发天空重烘。旧渐变环境的定时器不能覆盖物理天空；切回经典模式恢复旧环境所有权。
- 曝光为 `2^EV × ISO/400`；编辑视图以 ISO 400 为基准，预览和 PNG / 视频导出取最终机位 ISO，只乘一次。导出后立即恢复原曝光；光圈、快门暂不参与测光。
- 相机白平衡为近似 RGB 色温适应，在通用材质与天空的 tone mapping 之前生效；不改原始材质颜色，不烘进环境反射，兼容既有地形 / 透明材质 shader hook。不是光谱渲染或任意第三方 RawShader 的保证。
- 距离雾为经验色 `FogExp2`，不是体积散射或真实空气透视。太阳和天空亮度为预演增益，不是绝对照度校准 / GI。

### 路灯、宫灯与预算

- 路灯、宫灯杆、既有落地灯增加按平方反比衰减的实际点光源；灯位应用物体旋转、缩放与运动后的完整变换。宫灯杆两盏灯各自发光，共用光通量并按比例分配，各占一个光源槽位。
- 物体页独立「灯具照明」：自动 / 强制开 / 强制关、灯罩自发光、是否照亮周围、光通量、作用半径、模型灯色 / 光源色温、申请投影。旧宫灯的亮度入口统一放在此处，避免两套互相覆盖的控件。
- 自动模式随太阳高度在 -3° 至 +5° 间渐变；经典模式沿用氛围预设发光水平。强制开关不受昼夜控制。灯罩自发光与实际照明独立，远处或预算外仍保留自发光。
- 每实例克隆发光材质，不修改共享库材质；发光灯罩不遮住自身内部点光源。模型重建、删除、隐藏、材质开关和内存优先均参与更新。
- 灯光预算按最终渲染相机距离筛选，切换留有滞回、距离边界渐隐；池化点光源避免每次换灯都重建整套光源数量。配置支持保存与撤销。

| 档位 | 最多实际点光源 | 最多灯具投影 | 相机筛选上限 | 单面阴影尺寸 |
| --- | ---: | ---: | ---: | ---: |
| 低 | 4 | 0 | 45m | 无 |
| 中 | 8 | 1 | 70m | 512² |
| 高 | 12 | 2 | 100m | 512² |

- 距离还受灯具作用半径 + 40m 的上限限制，最后 10m 渐隐；投影还受全局及单灯开关限制。点光投影每盏需渲染六面，预算外光源不投影，可能穿墙漏光；不是所有灯都能同时遮挡。太阳阴影另设低 / 中 / 高质量，覆盖当前视点附近。
- 关闭光影 / 内存优先时停用实际灯光与物理环境引用，保留配置和可恢复缓存；不声称释放了所有显存。
- **本轮边界**：未新增 bloom 泛光、建筑窗户实光 / 专属开关、体积云或复杂夜空。建筑旧自发光沿用旧机制。第 5 项完整窗户 / 辉光体系尚未完成；第 6 项首轮诊断与资源治理见下文，不代表全面性能治理完成。
