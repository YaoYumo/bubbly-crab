## 当前处置

- 暂停推荐该安装包，不建议保留、运行或关闭浏览器 / Windows 安全防护。
- 不改后缀、不加密压缩、不通过更换下载域名规避判定，也不发布一个内容相同的替代包来掩盖告警。
- 原始构建 run `39891196400`，源码 `e9b4e00d2ea4054f6598586082ea77460452af36`，artifact `12475121975`。
- 对原始 GitHub artifact ZIP 验证 GitHub 上传摘要，再核对其中安装器和应用 exe 与原 Windows 构建清单一致；不重新编译一个不同二进制冒充被阻止的原件。
- Windows runner 使用系统 Microsoft Defender 检查 ZIP 和解压内容。不执行应用、不关闭保护、不添加排除项、不自动恢复隔离文件。
- 记录扫描引擎、签名版本和日期、更新状态、退出码及检出。扫描器不可用 / 定义过期 / 权限不足 / 异常均不视为通过。报告通过 GitHub annotation 与 JSON 保存。
- 单一引擎无检出不等于软件安全或浏览器信誉通过，也不构成要求用户忽略阻止的依据。

流程：`.github/workflows/windows-package-security.yml`；实现：`scripts/windows-security-scan.ps1`。

## 签名与后续

安装包尚无可信代码签名。受信任签名有助于身份与信誉，但不能保证立即消除浏览器告警，更不能替代安全检测。若有具体检测名称，应先调查 / 修复或向对应安全厂商提交复核，不能假定只是签名问题。自动购买 / 获取签名证书或把文件上传其他扫描平台不在本次排查中。

检测结果尚未返回时，不声称“已修复下载”或“确认无毒”。
