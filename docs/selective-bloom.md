# ② 选择性 Bloom · 窗灯与指定表面

2026-10-18。①冷构建与限定规格长视频阶段之后的可选范围扩展；③地形导入 / 侵蚀 / 河网尚未开始。当前交付包与本阶段源码指纹见 [selective-bloom-evidence/manifest.json](selective-bloom-evidence/manifest.json)。此前①、LOD / Bloom 首版的 manifest 是各自历史快照，不能用其旧包哈希校验当前包；本阶段没有重做①的两条 30 秒逐帧长片验收。

## 使用

1. **Scene → 光影 → Bloom · 泛光范围**，启用 Bloom，来源选「选择性 · 窗灯与指定表面」。缺少新模式字段的旧工程仍用「全屏高亮」，默认开关仍关闭，不迁移旧画面。
2. 需要建筑窗光时打开「自动纳入库建筑窗面」，并在窗灯设置让窗面真正发亮。自动选择不是把反射明亮的玻璃涂成光源：窗灯关闭或点亮比例为零时，不从玻璃反射提取光晕。
3. 选中物体，在 **此物体 · 选择性 Bloom** 选择：
   - **跟随自动窗面**：只纳入已有库窗面识别规则，且受全局自动窗面开关控制。导入玻璃、汽车、水面不自动识别。
   - **仅下方指定表面**：勾选网格的材质槽；选择「仅原材质自发光」或「底色 / 贴图（灯牌）」。后者可让普通灯牌贴图作为光源，不取受光 / 高光 / 环境反射，不改原材质、不新增灯。倍率 0–16，只作用于指定模式。
   - **此物体所有自发光面**：原生 Standard / Physical / Lambert / Phong / Toon 取实际 emissive；Basic 没有 emissive，明确按底色 / 贴图处理。此模式是显式纳入，不要用它来排除 Basic 天空模型。
   - **排除此物体**：不提供泛光来源，仍保留其几何遮挡。
4. 表面列表可按网格 / 材质名筛选，每次显示 80 项，可追加；最多指定 256 项。合并网格只能按现有材质槽选择，不能单独挑它内部某一个窗户。自动窗面 / 所有自发光模式忽略列表和指定倍率。
5. 对象设置写入 `params.bloomSelection`，全局写入 `rendering.bloom`，支持复制、撤销 / 重做、自动保存和 `.previz` 工程包。锁定物体不可改。

使用自发光源时，仍需高于 HDR 阈值才有明显光晕。建议先用低强度；过大强度 / 底色倍率会让指定光源的光晕铺满画面。选择性不代表光晕只存在于源几何范围之内。

## 实现与边界

- 额外绘制全尺寸 **RGBA16F + 深度**光源缓冲。源材质的原生顶点、贴图、透明度、alphaTest、实例属性和窗灯编译 hook 保留；选中面只输出自发光，或显式选用的底色。非目标物体输出黑色并保留深度 / alpha 遮挡，不能通过隐藏它们造成穿墙泛光。
- 天空、环境背景、相机 rig、gizmo、辅助线 / 标记 / 粒子不进入光源缓冲。地形 / 水面 / 地面参与遮挡，但不提供光源；本版选择器支持 Mesh 材质槽，不支持线 / Sprite / 粒子发光选择。
- 只替换 UnrealBloomPass 的高通输入纹理；既有模糊金字塔仍将光晕加回原 HDR 底图，不把黑色遮罩当底图叠回。相机白平衡只乘一次；雾仅衰减源光，不把雾颜色当来源。
- 选择性遮罩不参与建筑合批，防止不同对象的选择范围被合并或临时材质污染实例缓存。底图仍可合批。LOD 期间用原始几何信息生成表面引用，绘制采用本帧 LOD 几何；最后恢复原对象。异常路径恢复材质、可见性、清屏色、目标、视口 / scissor、阴影更新开关及 LOD / 合批状态；Stage 也恢复失败前的 framebuffer，避免下帧关闭后处理时仍画入离屏目标。
- 表面引用不使用 UUID，由层级子索引路径、材质槽、网格 / 材质名称与类型、几何类型、顶点 / 索引数及子网格局部变换组成。根物体的摆放位置 / 姿态不进入引用。复制 / 原参数重建 / 存档恢复保持匹配；这些字段变化时失配并停止该引用，在物体页及性能面板报告。**不是几何内容全哈希或永久语义 ID**：同计数、同结构的几何内容变化未必失配，重建后需检查选择。
- 非原生 ShaderMaterial 保守地使用黑色原生遮挡替身并报告 unsupported，不提供光源；不能保证任意自定义顶点变形、alpha / 折射与 shader 回调的遮挡完全一致。透明材质沿用普通 alpha / 深度规则，不是物理折射 / 体积散射求解；未专项验证所有导入 shader、动画人物和多 GPU。
- 景深、宽银幕、黑边输出可组合，但选择性光源缓冲是原几何的 emission，**没有对该缓冲额外做 Bokeh 景深**，不承诺物理准确的焦外光斑。宽银幕导出仍沿用①的预览 / resize 限制。
- Basic 低内存模式或缺少 HDR 颜色附件支持时暂停 Bloom；模式 / 0 强度 / 关闭 / dispose 时释放目标和自有变体，不 dispose 借用源材质 / 贴图。运行中按 source.version 重建、按帧清理不再使用的变体，并同步窗灯 intensity / emissive 和相关贴图、透明 / 深度状态。

## 成本：不是性能优化

全屏兼容模式不创建选择性缓冲。选择性模式比旧 Bloom 多一次带深度的物理内容绘制；每帧遍历表面、生成引用与材质选择也有 CPU 成本。为隔离对象策略，该额外绘制没有重复建筑合批。原生材质的阴影更新在遮罩阶段暂停，避免再生成阴影图。

在本次 Chromium 131 / Linux x86_64 / SwiftShader、480×320、三栋建筑夹具的末次快照中：**431 个候选 Mesh、432 次实际遮罩 draw call、3 个候选来源槽**。遮罩目标约 **1,843,200B（1.76 MiB）**，按 HDR 8B + 深度约 4B / px 估算，仅此额外目标，不是全部显存实测；1080p 同样估法约 23.7 MiB，另有 composer、Bloom 金字塔等。选择低精度只缩金字塔，遮罩始终全输出尺寸。

性能面板报告实际 mask draws、候选源槽 / Mesh、失配 / unsupported、目标尺寸与估算字节。没有承诺 FPS / GPU 时间改善或硬实时预算。

## 本阶段验收

最终源码和正式单文件包分别在 DEV / **真实断网 file** 跑同一专项，均 PASS；数值详见对应 JSON。

- 未指定 HDR 亮面、HDR 背景、原生 Shader 天空、已指定但没有自发光的亮反射，与 **同一 composer 管线、Bloom 合成强度临时为零**的参考图 RGB 差值均为 0。反射控制点 RGB 最大通道为 **234**，避免拿纯黑反射做无效阴性对照。全屏模式正对照 RGB 均差约 **2.0244 / 255**，选择性 emission 正对照约 **151.812 / 255**（刻意的过亮测试源，不是推荐画面强度）。不拿直接渲染与 HDR composer 在抗锯齿边缘的差异误判成光晕。
- 非目标不透明遮挡下差值 0；alphaTest 裁切允许部分透光，均差约 **125.887**，小于无遮挡 **151.812**。多材质组只指定一个槽；未知 ShaderMaterial 黑色回退、unsupported=1、不提供泛光。
- 普通库窗面候选 7；点亮时缓冲 RGB 半浮点原始数值非零，熄灯 / ratio=0 为零；灰模仍保留窗灯发光。程序 GPU 幕墙 hook 点亮非零、ratio=0 全零；全局自动窗面关闭生效。这些原始半浮点字之和只是零 / 非零检查，不是物理亮度。
- 物体原生控件、指定范围 / 来源、一档撤销重做、复制、原参数重建、serialize/load 与真实 `.previz` 往返通过；失配引用不乱选；底图仍有 **71 组合批**，缓存未被临时材质污染。
- 组合 LOD：3 栋远景、4 个 mesh 简化、6 个细节隐藏、缓存 15,712B，选择引用无失配、结束恢复源几何；原始拾取 / gizmo 通过。
- 注入 mask 渲染异常后源材质 / 可见性 / framebuffer / tone mapping / shadow / LOD / 合批恢复；之后可正常渲染。
- DOF、宽银幕、Basic 暂停恢复、黑边及 PNG 冒烟通过。每入口导出 **480×320 @5fps / 0.4s / 2 帧 VP9 WebM**，FFmpeg 真解码 2 帧、RGB 非空。只是一条短兼容冒烟，不是重新验收选择性模式的长视频 / 大分辨率 / Safari。
- 两轮预热后四连开关平台相同：开启 **466 geometry / 31 texture / 62 program / 63 变体**，关闭 **465 / 19 / 47 / 0**；每次释放 12 张光源 / 金字塔纹理。不是跨浏览器、无限循环或设备显存无泄漏证明。
- 既有 LOD / 全屏 Bloom、窗灯、照明及拾取 smoke 均在 DEV / file 通过；Node 选择性、effects、cold-work、647 拾取对照、窗灯、道路诊断、路口面积 / 射线检查通过。未重跑全部历史总门禁，也未重新跑四场景完整长基准。
