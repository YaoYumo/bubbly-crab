# 一句话精细场景配方 · 第一批

2026-10-20。当前支持 **赛博街谷** 与 **滨河古城** 两类本地、可参数化的程序场景。它们和两套精选示例共用资产与 `buildShowcaseScenes(options)`，不是只给固定场景换颜色，也不是任意自然语言自动建模。

## 怎么用

1. 在 **Scene** 页点顶栏 **一句话生成**。
2. 点击前两条例句，或输入下方文字；配方自动识别，也可显式选择「赛博街谷 / 滨河古城」。
3. 展开 **配方参数**，调整当前类型适用的数值、开场机位；文本重新输入会清掉手动覆盖，重新解析。
4. 点 **预览布局（不改当前工程）** 看河、路、建筑和青色机位标记。这是 **二维布局草图，不是最终 3D 候选**。
5. 点 **生成街区**。它替换当前工程，先保存重要工作；成功后 **Ctrl+Z** 一步退回，重做可恢复。同 seed、同参数生成相同布景数据。
6. 模型、组合件部件、机位与动作路线都可继续编辑；**场景 → 保存工程** 导出 `.previz`，打开后恢复生成来源与组合件元数据。按空格播放 30 秒动作，Camera 页选机位取景。

可直接粘贴：

```text
赛博都市，30层高楼，8辆悬浮车，20位行人，大雾下雨，夜景，种子82
```

```text
中式古城沿河两岸，河宽16米，石拱桥，中轴道路，牌楼跨街，佛塔，120盏孔明灯，28位行人，夜景，种子42
```

也识别白天／黄昏／夜景、晴天／雨／雪、无雾、无人／无车／无孔明灯、鸟瞰、直河、稀疏／繁华等受控表达。不是完整自然语言理解；未理解、缺少或不支持的能力会在解析区提示，不能假设任意句子都能精确执行。

不命中这两类语义时，保留原有普通造镇、场景模板、道路布局入口。手动选普通模板优先于自动配方识别。配方本身保留街谷／双岸中轴骨架，**不应用普通造镇的方格、放射、环路布局**，遇到此类要求会说明；需要这些路网请使用普通造镇。

## 参数与结构变化

| 参数 | 受控范围 | 实际作用 |
| --- | --- | --- |
| seed | 1–999999999 | 改变城市街距／体量、古城河弯方向和形状等，不仅改颜色 |
| 场域 | 256–384m | 城市用离散排数改变规模；古城改变沿河纵深／地形尺度，不是无限扩图 |
| 密度 | 0.2–1 | 城市 5/7/9 排的受控组合；古城每岸 6/10/12 个候选铺位，塔院留空会减少实际铺位 |
| 楼层基准 | 12–40 | 城市主楼体量基准，楼间有变化并限制范围，不保证每栋相同层数 |
| 悬浮车 | 0–12 | 仅城市；纵向航道及足够数量时的横穿航道 |
| 行人 | 0–48 | 两类均适用；古城先安排最多 4 位桥上游人，其余沿岸 |
| 河宽 | 12–20m | 仅古城；联动双岸与桥跨度，桥跨度为河宽 + 10m |
| 孔明灯 | 0 或 12–180 | 仅古城；0 关闭，其余分 3 个可编辑灯群；1–11 会提示并归一到 12 |
| 开场 | 街面／沿河／全景 | 对应当前类型的开场位置；首个保存机位与开场位置／朝向一致 |

字段按场景类型显示；两类共用的归一化记录中可能保留不适用字段，它们不会凭空生成另一类资产。超范围数值会提示限制，非有限数字拒绝。每景预算最多 240 个声明式库模型（原生道路及派生路口另计）。

## 公共资产与组合规则

- 原模型库只增不动；使用已注册的 7 个示例公共资产：悬浮车、霓虹牌、雨街地面、空中步廊／消防梯、滨河栏杆、暖窗格栅、水面碎金。没有让 AI 临时执行建模代码。
- 本轮只扩新增资产的受控参数，例如悬浮车尺寸、地面车道／横街、河面碎金形状，保留原有库模型参数范围。
- `scene-kits.js` 提供「赛博商业立面」「滨河暖窗商楼」，按宿主局部坐标和朝向挂接招牌／窗格。部件是普通独立对象，可分别编辑，`params.sceneKit` 记录组合、实例及挂接点。
- **挂接在生成时计算，不是持续父子约束**。生成后移动或改宿主尺寸，不会自动移动／重挂其独立招牌、窗格。
- 雨雪、雾、Bloom、夜窗和动作是环境／行为系统，不当作新的模型能力。湿街及水面碎金是美术效果，不是 SSR 或光追反射；灯群不是逐灯实时光源或逐盏物理模拟。

## 空间与事务保证

生成前以及修改工程前分别预检：资产／灯具参数与预算、动态路线有限坐标、每路线 241 个样本、飞车对保守塔楼包围盒的净空、城市开场不在塔楼内、桥跨河岸、中轴道路不盖河桥、牌楼横跨中轴、民居商铺不侵入两座佛塔的保留场地。

这是 **这两类受控骨架的规则与采样检查**，不是任意 mesh 的碰撞求解、通用空间关系引擎、导航避障或自动电影构图评分。开场来自配方预设及参数联动，已有截图检查，不承诺所有用户编辑后仍无遮挡。

整场应用期间暂停 tick 和中途自动保存；与 AI、导出、参考包、地形及道路编辑任务互斥。超过 12MB 的当前工程会触发撤销保护，要求先保存／拆分。生成失败恢复原工程、人物 pose／phase、视图、选择及撤销重做历史；成功再保存本地。Esc 可取消开始前排队的生成，**同步应用开始后没有中途可交互取消**。
