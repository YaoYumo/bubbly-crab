# 1.1.0：主控时间轴镜头剪辑

此前时间轴只有临时片段外观：播放时由界面回调修改当前机位，暂停拖针不切镜头，工程不保存片段，视频导出也不读取片段。本次改为真正的单视频轨硬切剪辑，接入核心采样。

## 使用

1. 在左侧创建并调好多个机位。
2. 主控底部点击 **顺序拼接**：按机位列表顺序拼接，自动开启剪辑预览，并将工程总时长改成各机位时长之和。已有剪辑时会确认替换，可撤销。
3. 也可选好机位，点击 **+ 当前机位**，追加到轨道末尾；或将左侧机位拖入轨道指定位置。重叠会拒绝，不会悄悄覆盖其他镜头。
4. 点击片段选中；拖动中间移动，拖两端裁剪。鼠标编辑按工程帧率吸附；下方 **起／止／源入** 可直接输入秒数。左裁剪同步调整源入点，移动不改变源入点。
5. 点击轨道空位拖动播放头；双击片段定位入点。点击 **分割** 在播放头处分割选中片段，左右至少一帧，源时间连续。
6. **删片段** 仅移除片段，不删除机位。片段获得键盘焦点时 Delete／Backspace 也只删片段；焦点在时间轴以外时仍遵循原有场景快捷键。
7. 播放、暂停定位、当前帧 PNG、视频导出均使用同一剪辑采样。工程 `.previz`、JSON 和本地恢复包含剪辑；Ctrl+Z／重做涵盖剪辑操作。播放不会改掉检查器里的编辑机位。
8. 关闭 **剪辑预览** 回到原来的活动单机位模式，片段仍保留。编辑源机位的关键帧／曲线时，请先关闭剪辑预览；源机位运动时长与整段剪辑总时长分开。

顶部总时长不会把已有片段按比例拉伸；不得缩短到最后一个片段之前。改变已有源机位的时长，也不会再将整段工程误缩成该机位时长。追加／拼接改变工程总时长时，原有按全工程归一化的物体路径仍遵循原有时间机制；行为程序仍按其绝对秒数采样。

## 时间与兼容规则

- 当前范围：**单视频轨、硬切、最多128段、总长0.5–120秒**；没有音轨、叠化、变速、自动波纹删除。移除原来未实现的 Audio 占位轨，避免误解。
- 秒制非重叠区间；切点正好到下一段起点时切入下一镜头。空隙保持前一片段的镜头出点，首段前保持首段入点，工程终点保持最后一段出点。场景物体继续按全局时间运动，不是冻结整幅画面。
- 镜头运动按1×源时间播放：`sourceIn + (工程时间 - 片段起点)`，除以源机位时长得到路径进度。超出源机位时长后保持末态。分割不会重新开始镜头运动。
- 镜头引用稳定 `shotId`，不依赖列表序号。机位重排不串镜；删除机位同时移除引用它的片段，撤销删除可一起恢复。
- 剪辑模式逐帧独立采样，重置机位历史滤波缓存，避免切镜头／倒拖时继承上一镜头的跟随／注视／避地阻尼。关键帧路径插值和确定性的手持仍有效；这是受控硬切首版，不宣称带历史阻尼的电影级剪辑／转场。单机位模式原有滤波保持不变。
- 视频导出结束、取消、失败后恢复工程与机位运行态（包括自动对焦距离），不将最后一个输出镜头写成编辑选择；视频文件名使用 `camera-edit` 标记。
- 旧工程没有 `cameraEdit` 字段，默认单机位，不会擅自生成剪辑。**含剪辑的工程请使用1.1.0及以后；旧版会忽略剪辑，旧版重新保存可能丢失它。升级前先另存备份。**
- 参考包／逐帧诊断目前仍针对单机位。开启非空剪辑时会明确阻止生成参考包并提示先关闭剪辑预览；不混用多机位画面与单机位元数据。整段剪辑使用视频导出。
- 播放、导出、参考包、场景／行为／地形后台任务期间拒绝编辑剪辑。

## 实现与回归

- `src/camera-edit.js`：不可变、版本化的数据校验与独立采样；`App.cameraSample/applyCameraSample`：核心播放、暂停定位与导出统一入口。
- 工程新增 `cameraEdit: {version:1, enabled, clips:[{id,shotId,start,end,sourceIn}]}`，仍为现有v4工程的可选扩展字段。载入前先验证片段格式、机位引用、时间范围、重叠，失败不先清空场景。
- `npm run test:camera-edit`：纯数据单测及真实 Chromium 回归；覆盖切点／终点／循环、反向定位一致性、稳定选择、JSON／.previz工程包／本地恢复存取、错误载入不毁场景、撤销重做、删除机位及撤销、机位重排、旧工程、参考包保护、导出锁与取消／失败清理、可见控制、鼠标移动／裁剪及聚焦删除。
- 两条视频路径实际编码并解码检查：WebCodecs 固定时间戳与 MediaRecorder 兼容录制各6帧，0.3秒时由Cut A切到Cut B；检查采样调用序列和前后解码像素差异。**MediaRecorder仍不保证固定时间戳／不丢帧**，像素差异仅为小规格测试，不是用户GPU完整验收。
- 同一剪辑回归在无网络的 `file://` 离线 HTML 上通过。新增剪辑回归也在模拟Tauri CSP的桌面前端上通过（零CSP违规，浏览器预检不执行真实原生保存）。原有桌面前端预检（模拟原生保存IPC）及离线单机位参考包回归通过，主题颜色／相机标签不回退。联网参考包完整回归依赖本地5176网关；本轮未启动网关，web版本在网关发现步骤超时，不能记为完整通过。
- 可复跑：`TEST_FILE_URL=file:///完整路径/previz-lab.html bash test/withchrome.sh node test/camera-edit-regression.mjs`。浏览器证据见 `camera-edit-evidence/`。这些是Linux Chromium结果，**不是Windows WebView2原生交互验收**。

Windows 1.1.0安装器已真实构建并通过安装／窗口启动检查，不复用1.0.1显示修复包；当前下载与准确原生检查边界见 [桌面安装说明](desktop-windows.md)。没有合并main、发布Release、签名或运行模型。
