# 多步骤行为与静态导航（第四阶段首版）

2026-10-21。本功能是本地确定性行为编排，不调用 AI，不下载或启动模型，也不把任意中文指令直接转成可执行代码。此前三阶段的本地模型工具、受控关系与编辑后联动继续保留；真实模型仍未启用／验收。

## 使用

1. 进入 **Scene**，选择模型库中的**单个人物**（男性、女性、儿童、施工人员、西装商务）。暂停播放，把工程时间轴拖回 **0 秒**。
2. 本版只在**世界 y=0 平面**工作。请在地形页自行关闭地形；系统不会替你关闭地形、挪人物或清理障碍。不支持人群、导入骨骼、挂接人物、倾斜或非均匀缩放的人物。
3. 在右侧人物检查器打开 **多步骤行为 / 静态导航 → 编辑步骤 / 独立预演**。
4. 按顺序添加步骤、填写秒数：
   - **移动**：世界 **X、Z** 目标，步行／跑步；不是相对位移，也不是 Y 高度。
   - **停留／动作**：停留、挥手、指向、说话、观察、看手机；可指定世界 XZ 朝向点。不提供坐下接触、抓取、双人交互或自动对话。
   - 可上移、删除步骤。需要最终站立时，请在末尾显式增加“停留”。
5. 设置代理半径、代理高度、网格间距与范围余量，点 **生成独立预演**。独立窗口显示新建的人物、实际折线路径和参与导航的障碍代理；可播放或拖动候选秒数，不修改现场人物、时长或撤销栈。
6. 阅读覆盖计数和限制，勾选限制确认。行为超出工程时长时，还必须明确同意延长时间轴；只延长工程时长，不改写各机位自己的时长。点 **确认应用（一步撤销）**，关闭窗口，再播放或拖动主时间轴。
7. 保存工程／`.previz`，行为随对象保存。**Ctrl+Z / 重做**恢复整套方案和时长。修改起点或身形时，先回到0秒，在该窗口明确移除现有方案，然后编辑人物；移除也可撤销。复制人物会移除副本的方案与生成路径，避免副本突然回到原人物的世界路线。

候选不会自动应用。编辑步骤或代理设置会销毁旧预演并取消其应用资格；关闭／丢弃会释放独立预演资源。候选生成后工程发生变化，应用时会拒绝，必须重新预演。

## 时序与动画

- `motion.behavior` 使用 `previz-behavior/1`，保存结构化步骤和编译后的世界坐标折线，不存运行中的 Mover、骨架或 GPU 资源。
- 每个移动步骤按**该折线弧长匀速**分配该步秒数，步间、转角与动作切换为**硬切**。不使用 Catmull-Rom，不用会穿角的平滑近似。
- 位置、朝向和动作姿态均由**绝对秒数**计算；重复采样／暂停／前后跳转不累加 `dt`。行走相位按路径距离计算，停留动作按该步骤局部时间计算，不等于足底接触或自动步速求解。
- 末尾**保持最后一帧姿态**，不会自动转为站立，也不会自行重启。只有主时间轴循环才从头采样；工程时长大于行为时长时，多出的部分保持末态。
- 生成的路径与人物变换／模型参数为只读，不能拖绿色节点、按 K 改路径或用 gizmo 悄悄改起点。请重新预演或明确移除方案。原来没有行为方案的走位、Mover、动作与人群逻辑保持原入口。
- 工程载入只做有界的**结构校验**，不重新规划或静默修复路线；损坏的方案禁用且不会回退执行兼容关键帧。后续启用地形也会停用平面行为，需关闭地形后重新预演。

## 导航保证与不保证

保证只针对**本次确认时**参与检查的静态几何 **AABB**，以及**输入的半径／高度代理**：

- 对可见静态库资产、绘制道路／路口、植被块提取保守世界包围盒；实例按各自矩阵合并。人物和活动运动对象不是静态障碍，特效分类忽略；会报告这些计数。导入／未知静态对象、骨骼／morph／ShaderMaterial 变形障碍和不可逆变换拒绝，不默默声称完整覆盖。
- 除明确地面／道路类别且薄层位于 `[-0.2, 0.12]m` 外，障碍需与 `[-0.001, height]` 高度带相交才参与 XZ 导航。整个资产只取一个 AABB，门洞、院落、树间空隙等可能被保守封死。
- 障碍平面盒按输入半径加 `0.001m` 膨胀。确定性四邻格 A*，边与连接线逐段检验，最后视线简化只保留经检验的线段；不会用曲线替代折线穿过墙角。
- 在所有目标范围加余量的有界网格内寻找路径。网格过粗、起终点网格中心不可达或边缘净空不足时，可能拒绝一个现实中可达的目标；请减小间距、扩大余量或调整目标。**不承诺最短路径或必然找到所有可行路径**。

**不是** NavMesh、动态避让、车流协调、多人社交行为、精确网格碰撞、角色四肢扫掠、脚底锁定、坐椅／抓取接触、水域与地面支撑检测、楼梯／坡地／多层地面导航。半径／高度是用户设置的代理，不会自动按身形、挥手幅度或携带道具推导完整体积，必须自行设置保守值并检查预演。

保存的是已确认的静态路线快照。**之后移动／增加障碍不会自动改路或获得新一轮净空保证**，应按需重新预演；不会逐帧扫描全场景或自动覆盖作者编辑。

## 事务、导出与互斥

预演只读工程；应用前再次验证工程 SHA-256、重新编译并比对整个候选。必须在0秒、非播放／导出／参考包／AI／地形／侵蚀预览／道路／植被／拖拽任务中操作。应用、移除有撤销快照与整批回滚；写入后异常、撤销保存失败、已 append 快照后异常都会恢复 motion、人物姿态、变换、时长、选择与历史栈。

通用 PNG／视频导出的快照额外保存对象真实变换与人物关节、相位／漫游状态，成功、取消或失败都恢复现场。行为本身使用绝对采样；旧角色的增量动画不被替换成新算法。

`motionJson()` 的行为主体明确标识绝对秒数与折线插值，并附完整方案；提示词增加至多8个行为主体的秒表摘要，不再把它们统称为单一 walk cycle。参考包工程源、运镜 JSON 和提示词保留这些信息；正常／灰模及关键帧深度、ID、主体遮罩使用同一时刻的角色姿态。这不代表第三方视频模型一定支持这些结构化输入。

## 硬预算

| 项目 | 首版限制 |
|---|---|
| 步骤／时长 | 1–16步；每步0.1–60秒，总计≤120秒 |
| 编译路径 | 全方案≤256路径点；方案≤128KiB |
| 目标／世界 | 目标XZ±590m；导航范围±600m；只y=0 |
| 代理 | 半径0.05–2m，高度0.5–5m |
| 网格 | 间距0.25–2m，余量2–30m；每条路径≤16384格，每轴≤256格 |
| 几何检查 | 整套编译共≤200万次障碍线段测试，不是每步各放宽200万 |
| 场景／障碍候选 | ≤2000对象；≤512可见静态候选，含之后因高度／地面规则排除的对象 |
| 几何提取 | 全批≤25000网格／实例；未缓存bbox≤300万顶点 |
| 撤销保护 | 工程快照≤12MB |

预算或不可达会明确失败，不发布穿墙兜底路线，不自动粗化网格、不传送人物。首版求解为有界同步计算，没有后台持续寻路。

媒体专项实际生成 **320×180、4fps、8秒／32帧 WebCodecs 视频**，检查 walk→wave→run 和成功／取消／失败现场恢复；生成 **320×180、2fps、8秒／16帧** 正常／灰模参考包及三组深度／ID／主体遮罩，检查源工程、动作JSON、提示词、恢复与两次**固定机位**的首末PNG字节一致。此处视频帧数来自编码器／muxer回报和采样回调，**未另用外部解码器逐帧统计**；不把它扩写为跨相机模式、跨GPU／Safari或高规格长片总验收。一次带平滑主体跟随的探索未得到稳定的首末PNG字节一致，因此本次可重复像素证据明确仅限固定机位，不宣称解决原有机位高度缓存／平滑的全部时序问题。
