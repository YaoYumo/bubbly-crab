2026-10-18。按用户选择：**PNG 高度图 + PNG/JPEG 地表贴图，手绘河道优先，再加入侵蚀**。本次交付导入与手绘河道，不将河床刻蚀冒充热力 / 水力侵蚀；自动汇流、自动河网、水文模拟尚未实施。

## 高度图

1. 选通道，再选本地 PNG。支持 **8/16 位、非交错、灰度或 RGB**，以及 alpha 全不透明的对应 PNG；不支持调色板、Adam7、透明 / 缺失高程。文件不超过 16MiB，单边不超过 4096，像素总数不超过 4,194,304，最小 2×2。
2. 设置覆盖尺寸 **40–600m**、输出网格 **33–513 个奇数顶点 / 边**、黑值高程 **−5000–5000m**、黑到白高差 **0–5000m**。输入尺寸与现有编辑器保持一致，不是 GIS 坐标 / CRS / DEM 单位解析。
3. 默认灰度 / 红通道，也可选绿、蓝或原始 RGB 数值的加权灰度。**数据不经过浏览器颜色管理 / gamma / Canvas 的 16→8 位转换**。只有缩略图用 8 位显示。
4. 支持左右、上下翻转及黑白反向。原图上边对应世界 −Z、右边对应 +X；矩形图像双线性重采样并拉伸到方形地形，不自动保持地理长宽比。
5. 「应用高度」才修改地形，一次撤销可恢复。会覆盖全部高度、清空手绘材质权重、夸张重设为 1、启用自动底材，并走既有物体 / 地基 / 道路贴地联动。已有河道的世界坐标不随尺寸缩放。高度很大时可点「查看地形全貌」，只调整浏览相机，不改机位；超大高程的镜头远裁剪仍需自行设置。

PNG 解析包括块 CRC、zlib Adler、预期解压长度与行过滤器 0–4 校验；逐块有上限地解压，拒绝超出声明范围的数据。读取、重采样和刻蚀在主线程协作让出，不是 Worker 或硬实时预算；文件读取、原生贴图解码、CRC、网格 / 法线重建仍可产生长任务。可取消尚未发布的任务。

导入 / 刻蚀后的高度按 **Float32** 内嵌存档，避免旧厘米量化丢失 16 位采样细节。极大的基准高程加微小高差仍受 Float32 米制精度限制，并非无限精度。工程保存转换后的高度与导入参数 / 文件名，**不保存原始高度 PNG**；重新选择原通道、原图或重映射时需再选文件。

## 地表颜色贴图

- PNG / JPEG 输入不超过 16MiB，单边最多 8192、总像素最多 16,777,216。先检查头部尺寸，再用本地 ImageBitmap 解码；最长边缩至 **1024**，以 PNG data URI 内嵌工程。编码后约 **2MiB** 上限，过大应缩小原图。不能填写外部 URL。
- 使用 sRGB 颜色纹理，覆盖在自动底材 / 手绘材质颜色之上。混合 0–1；透明像素保留下面的颜色。**不改变高程、粗糙度、法线或物理材质权重**；1 为完整颜色覆盖，0 可恢复原地貌外观。
- 贴图的左右 / 上下翻转与高度图独立；非方图同样拉伸到方形地形。JPEG 不依赖 EXIF 方向自动纠正，请用翻转或先在外部旋转。
- 全局关闭物品材质或 Basic 低内存模式时暂停这张颜色覆盖，不丢失内嵌数据；重新开启恢复。地形原有自动配色仍沿用旧策略，不承诺整张地形变成灰色。
- 替换 / 移除 / 清空释放 owned texture；异步解码完成后发现工程已重置时丢弃结果。恢复贴图不发网络请求；PNG / 视频导出会等待恢复完成。自动保存沿既有 IndexedDB / 本地恢复机制接入，未单独保证各浏览器的存储额度。

## 手绘河道

### 绘制与编辑

1. 启用地形，点「新建 · 视口点击布点」。左键点地形放控制点；右键仍可旋转。Enter 停止布点，Backspace 删除最后一点，Esc 取消预览。也可通过「增加坐标点」和表格直接输入。
2. 每个点是 **X / 水面标高 Y / Z**（世界米）。初始标高为点击地形处高度减 0.15m；之后可逐点调整。宽度 **1–60m**、中心切深 **0.1–30m**、岸坡过渡 **0.5–60m**。支持名字和河面开关。
3. 预览只画引导线 / 河面，**不实时修改高度**。「保存河面 / 路径」只保存定义；「保存并刻蚀河床」才应用高度修改。已保存路径可重新编辑并刻蚀。
4. 最多 **16 条，每条 2–64 点**。端点 / 支流可由用户手动对齐标高形成造景河网；没有自动接缝、布尔汇合或自动流向求解。单条中心线自交、重叠折返、重复点、越界坐标和过尖转角会拒绝；邻近宽河道仍可能发生河面重叠，请留足距离或拆分调整。

### 河床与河面

- 沿折线路径插值水面标高，最近段距离决定圆弧形河床和岸坡；**只降低，不筑坝 / 填高**。中心目标为水面标高减切深，边缘仍保留约 20% 切深，外侧岸坡平滑衔接外部地形。夸张系数下按世界米换算切深。
- 核心刻蚀不是每点反复扣深；但相邻河道 / 连续重刻的岸坡受当时外部地形影响，不是完整幂等或可逆的地形图层。没有沉积、泥沙搬运、守恒侵蚀或水量模型。
- 河面为透明 PBR 折线带、共享有界 miter 接缝，不是流体、瀑布、流动纹理或河岸生态系统。可以人为设成上坡水面，编辑器不把它当作物理正确的水流。
- 删除河面 / 改路径 / 关闭河面 **不会自动回填旧河床**。需要恢复时先撤销再重刻，避免覆盖其他地形笔刷编辑。低于原地形的河面可能被遮挡，必要时刻蚀；高于低洼地的河面也不会自动筑岸或形成洪泛面。
- 建议河宽至少约 **2 个地形网格间距**，窄河道应提高网格密度，否则可能没有足够顶点刻出形状。雕刻只作用于地形边界内，靠边河面带可延伸出部分宽度。
- 地形尺寸变小导致已保存中心点越界时，该河面暂停，路径保留以便编辑或恢复尺寸。尺寸、夸张、地形生成 / 导入不会自动移动或重新定高河面。
- 局部河面与原全局海面独立；海面盖住河床时请关闭海面或调整海拔。既有地基 / 道路重新贴地可能重整局部河床，跨河桥建议用固定标高；没有新增水域碰撞 / 防洪 / 桥墩水动力规则。

保存数据在地形 `workflow` 下，不新增模型库项或替代 SceneObj。河面忽略拾取，地形拾取仍是原高度场；河道点先用表格编辑，不是 SceneObj gizmo。进入其他笔刷 / 道路绘制 / 页面会取消未保存预览，建议先保存。

## 事务与组合

- 高度计算在副本完成，发布前核对取消代次、源高度 / 材质权重、网格引用和相关状态；刻蚀期间源高度被其他编辑改变时拒绝覆盖。取消不留下半成品或额外撤销条目。
- 保存、复制工程、撤销 / 重做、`.previz`、清空均接入地形序列化。路径 / 颜色贴图与最终高度随工程保存，原始选图文件不再是播放依赖。
- 计算期间 PNG / 视频导出拒绝启动；导出中不启动新地形任务。已有恢复贴图会等待解码。导出隐藏河道预览并恢复 guide 状态。
- ②选择性 Bloom 将真实河面纳入黑色遮挡，不将河面反射当光源；预览引导不进该缓冲。旧全屏模式仍按全屏高亮规则工作。
- 没有改变模型库定义或恢复分享入口；没有宣称侵蚀 / 自动汇流已经完成。

## 本阶段验证

Chromium 131、Linux x86_64、ANGLE SwiftShader 软件渲染。**DEV 与真实断网 file 均通过新专项**，数据和执行日志见 evidence。只覆盖此环境，不是跨浏览器 / 多 GPU / 全格式导入验收。

- 原生文件选择输入 16 位 PNG，设置 65×65 / 80m / 黑值 2m / 高差 1m。原采样 10000 与 10001 分别成为 **2.152590274810791 / 2.1526055335998535m**，撤销、重做、JSON、工程包往返均逐 Float32 相等，不量化为同一厘米值。
- PNG / JPEG 颜色覆盖真实像素：原自动底色 `[154,194,129]` → 红覆盖 `[254,94,80]`，混合 0 回到原像素；灰模 / Basic 暂停恢复通过。四次替换纹理计数 **8 / 8 / 8 / 8**。
- 三次真实视口点击恰好三个点；宽 12m / 切深 2.5m，保存路径不改高度；刻蚀 **886 个顶点**，空场景中结果逐点不高于源高度。河面像素 `[106,147,166]`，隐藏后为底材 `[254,94,80]`，不是只有 JSON 没有画面。
- 刻蚀的一步撤销 / 重做、取消不修改高度或 undo、并发源编辑不被覆盖、缩小边界隐藏 / 恢复路径、工程包精确往返、清空释放纹理通过。
- 四次预览创建 / 取消平台均 **15 geometry / 9 texture**。这不是无限循环或设备显存泄漏证明。
- PNG **480×320** 非空；每入口 **0.4s @5fps / 2 帧 VP9 WebM**，FFmpeg 原生解码两帧且 RGB 非空。只是一条短兼容冒烟，不是重新验收本阶段的 30s / 120s 长片或 1080p 视频。
- 既有地形生成 / 自动地貌与地形 UI 的 DEV / 断网 file 回归通过；既有地形道路回归 **DEV** 通过（该旧测试依赖开发调试对象，未将其冒充 file 验收）。选择性 Bloom 与原生 MediaRecorder 兼容检查均 DEV / 断网 file 通过。Node PNG、河道、effects、cold-work、647 拾取、窗灯、道路诊断和路口检查通过。
