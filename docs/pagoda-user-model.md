## 文件实际情况

- 输入：用户上传 `Pagoda.zip.base64.txt`，严格Base64还原出604,052字节的ZIP；仅含 `Pagoda.gltf`，原始glTF为4,589,833字节。
- ZIP SHA256：`7499f9fb4a5360818fe1ccae6109ddac2e18b6ee1e54363467d1f4e8054207d3`。
- glTF SHA256：`e4d508a51cc1cccec89e1c7101cf362a5d28e0d9ce4b9b5d0d2e7f7f3318be1e`。
- 540个节点、531个静态网格、34,392个三角面、103,176个顶点。
- **原文件中材质0、图像／贴图0、动画0、骨骼0**。因此接入为中性灰模，不是导入时丢了材质；没有伪造瓦片／木材贴图或动画。灰模可在检查器整体调色。
- 原坐标包围盒尺寸约13.304 × 23.902 × 18.975个单位。未提供真实单位说明，暂按米解释，默认高度沿用原始尺寸，可按实际建筑高度调整。
- 将XZ居中、底面移到Y=0；保留原坐标轴和模型比例，不猜测或另转“正面”。
- 仅将这个无材质、无动画的静态模型烘焙为1个绘制网格；保留全部三角面／源法线及可用UV，没有减面。缺UV部件补零仅为统一布局，不生成贴图。
- 保留原始glTF的压缩副本 `src/user-models/pagoda/source.gltf.gz`。发布构建只引用编译后的压缩几何与缩略图，不打包这个归档。

## 实现与复跑

- `src/user-models.js`：追加「用户模型」分类、独立类型及参数、缩略图。
- `src/user-models/pagoda/build.js`：同步解码内置几何，每个放置对象拥有独立的几何／材质，防止删除或重建一个对象破坏其他副本。
- `src/assets.js`：仅追加新分组；`src/panels.js` 对提供缩略图的条目启用图片，其余条目沿用SVG图标与原有布局。
- `node scripts/prepare-pagoda.mjs`：从归档重生成压缩几何和校验清单。脚本仅支持本次静态灰模，不会把带材质、骨骼、动画的后续模型悄悄压成同样灰模。
- `node test/pagoda.test.mjs`：源文件／几何哈希、三角数、尺寸／底面、调高／调色、实例独立性与删除后重建。
- `npm run test:pagoda`：浏览器中操作真实库条目，检查缩略图、放置、调参、复制／删除、撤销、JSON与 `.previz` 往返、精度重建、射线拾取、PNG和短视频导出，确认原库宝塔仍存在。
- 同一浏览器回归在完全离线 `file://` HTML和模拟Tauri CSP的桌面前端通过，均无额外网络请求或CSP违规。证据见 `pagoda-model-evidence/`。

上述浏览器结果来自Linux Chromium，不是Windows WebView2／用户显卡的原生验收。没有发布Release、运行AI模型或合并main。
