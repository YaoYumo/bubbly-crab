# Windows 1.4.0：对话控制地形、河道、路网与模型

[Windows 最新安装包与构建记录](desktop-windows.md) · [构建检查与摘要](desktop-windows.md)

## 用户使用

1. 安装完整的 1.4.0 Windows 版。程序附带 **llama.cpp b11829 Vulkan x64** 推理引擎，不附带模型权重；无需安装 Node.js、CUDA 工具链或另开模型服务。
2. RTX 4070 Ti / 12GB 显存建议先使用 **Qwen2.5-7B-Instruct 的 Q4_K_M GGUF**。模型来源建议：[Qwen 官方 GGUF 仓库](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct-GGUF/tree/main)。本环境未访问或下载该仓库文件，具体文件名、大小、许可证与完整性以发布者页面为准，避免下载来路不明的 GGUF。
3. 打开桌面“一句话生成”→“打开模型文件夹”，把 GGUF 放进去。这个 `models` 在安装后的应用 EXE 旁边，**不是放安装器 EXE 的下载目录**，也不是 `runtime/llama`。分片模型应完整下载所有分片，选择第一片。程序不会搬动、下载、删除你的权重。
4. 点击“刷新”。只有一个模型会自动选中；有多个可选择。输入“建一个中式院落，中间留出空地”，发送。程序首次发送时自动加载模型，后台校验后直接搭建。
5. 继续说“把刚才的第一座房子向右移5米，再加一座”。同一轮可以混合新增与修改；无需工作包、蓝图或候选预览。普通修改直接应用，可用“撤销上次修改”或关闭对话后 Ctrl+Z 撤销整轮。清空物体、或删除不少于三个且不少于现有一半物体时，必须确认。覆盖非平地形、手绘地表或导入高度也需要一次确认。
6. 模型卡住可点“停止”，本轮不会继续应用；已经进入原子提交的短暂阶段不能中断，完成后可撤销。显存不足或 Vulkan 驱动不兼容时，可在“本地模型设置”勾选 CPU 后重试（通常较慢）。关闭应用会终止应用启动的引擎。关闭对话不卸载已就绪模型，再打开可继续对话；退出应用后对话记录不保留，场景仍按现有工程保存机制处理。

## 实际能力与边界

- 支持程序已有的**地形生成、局部抬高/降低/整平/平滑、地表群系、河道刻蚀和独立河面、全局水面开关/水位、道路新增/路径及宽度修改/删除**；模型仍限已有目录素材与声明参数，不是文生新3D网格。灯光、时间轴、骨骼动画不属于此入口。
- 建筑和地形可混合同轮提交；新增 `ground` 建筑精确采样本轮候选地形。原有静态模型默认保留世界高度，可一起说“让原有建筑贴地”；只调整授权静态物体的根Y，不移动锁定对象或改写人物走位路径。已有道路/植被保持各自原有地形跟随规则。
- 地形类型为真正平地、平原、丘陵、山脊、岛屿、坑地、峡谷、台地；沿用当前网格分辨率，边长40–600米。局部操作最多8笔，半径1–150米且必须完全落在地形内。全局生成有锁定对象时拒绝，局部修改触及保护对象的保守XZ包围盒也拒绝，含隐藏锁定对象。
- 河道为路径式、**仅降低的程序刻蚀，不是水力或流体模拟**。每轮最多4项，总数16；编辑/删除河面不自动填回旧沟槽，可继续说局部整平。重生成地形会重新刻蚀保留的河道。水面默认关闭，`island` 不自动启用全局水面，河面与全局海/湖水面分别控制。不要求河流时不因“古城/路网”自动造河。
- 每轮最多48条模型指令，批量阵列展开后最多128项，单阵列最多60个；布局暂为X/Z各±300米。道路每轮最多16项、512个路径点，路宽2–20米。修改道路需授权且整个受影响路网无锁定对象；路口由已有道路系统生成。整轮候选资产仍受200万三角预算限制，30座民居不代表任意30座高细节宫殿都能同轮完成，超预算会拒绝而不私自替换素材。
- 全轮先在副本计算、全量验证，再一次应用/一次撤销；错误、取消、过期指纹、锁定/越权或提交异常不留下半个地形。格式或虚构目录key等模型输出错误**至多自动纠正一次**，界面明确显示纠正状态；业务拒绝、锁定、过期工程、停止及原生请求失败不会自动重试。上下文超限制明确报错，不静默截断工程，不执行模型返回的JS、shell、URL或任意工具名。
- 旧网页/离线HTML的本地配方与高级AI流程保持原样，公共v1蓝图没有新增地形或道路编辑权限；不会因为页面参数而获得桌面原生权限。Generate图片/视频网关仍不可在桌面直接调用。

### 可直接发送的例句

- “生成200米见方的丘陵，起伏8米，水面保持关闭。”
- “把东南方向X=30、Z=30附近半径12米的地形抬高4米，再把原有建筑贴地。”
- “在Z=35米沿东西方向造一条宽8米、深3米的河流，河面高度0米，不开全局水面。”
- “放30座中式民居，左右对称，留出中轴道路和两条横向道路，不要河流。”
- “把刚才的中轴路加宽到8米。” / “关闭全局水面。”

这些是工具覆盖范围的示例，不是指定硬件上真实Qwen必定正确理解的保证；如有歧义，补充方向/尺寸，结果不符可整轮撤销。

## 本机安全边界

Rust 只执行随包固定的 `runtime/llama/llama-server.exe`，只从安装目录 `models` 选 GGUF，拒绝路径穿越、目录外符号链接与不完整分片；不会执行模型文件。GGUF 仍由复杂原生解析器读取，并非无风险，请使用可信来源。

本机服务绑定 127.0.0.1 动态端口，每次启动生成256位随机口令；1.3.1 将端口分配、健康检查和推理 HTTP 全部移入固定随包的 `runtime/loopback/previz-loopback.exe`。主程序只通过有界标准输入/输出交换数据，不再为本地模型创建 Tokio/reqwest 或普通 TCP 套接字。辅助进程只允许 127.0.0.1 上 `/health` 与 `/v1/chat/completions`，使用阻塞 I/O，不读取代理配置、不跟随重定向。进程自身发生访问冲突会作为退出码返回，主窗口可显示错误；超时、停止和正常退出会终止辅助进程。前端不接触端口或口令，也不能提交任意 URL、启动参数或磁盘路径。只允许本地 `main` 窗口调用这些原生命令。请求64KB上限、回复1MiB上限、推理300秒超时。程序不上传对话；引擎日志在应用日志目录 `local-model.log`，可能含本机路径等诊断资料，不会自动上传。

引擎发布包固定为：
- `https://github.com/ggml-org/llama.cpp/releases/download/b11829/llama-b11829-bin-win-vulkan-x64.zip`
- SHA256 `839ff55ce9cbee6a099b403b640ca6b694ee5d74b815e39f77fc5d2b20962f0d`
- 官方 ZIP 36,876,542 bytes；打包前校验摘要，并携带原包内容及上游 MIT 许可证。

## 开发与验收说明

Windows 源码打包使用 PowerShell 7（pwsh），打包前运行 `pwsh -NoProfile -File scripts/prepare-desktop-engine.ps1` 和 `pwsh -NoProfile -File scripts/prepare-desktop-loopback.ps1`，再运行 `npm run desktop:build`。推理二进制只由脚本/CI准备，不提交到 Git，不把模型权重打包。

`test/local-scene-chat-regression.mjs` 在实际桌面构建+CSP预览中使用 **模拟原生推理 IPC**，覆盖直接搭建、地形+建筑混合且正确贴地、局部变形、河道/水面、道路增改删、30民居+3条道路、一次格式纠正、整轮撤销/重做、锁定含隐藏对象、过期指纹、候选篡改、准备取消和提交失败回滚、大删与覆盖地形确认、文件夹按钮。`test/local-scene-terrain.test.mjs`另测纯高度场计算、种子确定性、世界高度与水默认关闭等边界。它不代表真实 GGUF 推理成功。Windows CI另执行引擎 `--version`、Rust边界单元测试、原生编译、安装与窗口启动。**上述测试都不等于 4070 Ti 上 Qwen 的速度、显存占用或语义理解已实测。** 这些需要用户机器上的完整权重和实际场景验证。

## 1.3.1：ASProxy64.dll 崩溃兼容性修订

用户的 Windows 1.3.0 事件记录指向 `ASProxy64.dll 2.3.6.3 / 0xC0000005 / +0xC274`；引擎日志已到 `model loaded` 和 `listening`。这不是“没有放模型”的错误。记录定位到了网络拦截 DLL 内的故障点，但不是完整调用栈，也不能代表其他机器都具有相同根因。

1.3.1 不修改或卸载第三方软件，不删除 DLL、不重置 Winsock、不写代理排除注册表，不自动切换 CPU 或改变模型量化。修订的目标是移除 GUI 中本地模型网络 I/O 的触发路径，并隔离辅助进程的原生崩溃。即使辅助进程仍被不兼容 DLL 影响，也应返回错误而非因该进程的访问冲突带走 GUI。

编译/安装检查不会在 CI 中注入 Astrill DLL，也不会加载用户的 Qwen 权重，不能宣称用户故障已实机复现或消失。升级后仍需用户在原环境重试。建议升级前重启 Windows，清理旧版异常退出后可能残留的推理进程，避免显存占用或文件锁定；然后覆盖安装到原目录，两个 GGUF 保持原样。
