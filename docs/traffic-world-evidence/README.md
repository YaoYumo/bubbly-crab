# 1.9.0 原始回归证据

网页、断网单 HTML 与桌面 CSP 前端的 `web.json`、`file.json`、`desktop-csp.json` 来自最终综合测试。两个实际生成的螺旋接头均无城市灯控，保留有效主路 ID；隔离的主线车辆通过接头时最低速度约 10.8m/s，没有预约导致的停车。各接头有主线车道延续标线。随机特征存在且按种子重演。纯测另验证正负两侧含路肩六车道的精确标线位置、边界出生与重入场速度、出口不排队以及安全间隙让行。

`night-pools.png` 是实际夜间预烘焙光斑截图；每路一个批次、共享纹理，昼夜及载入开关同步，未创建实时灯。并非遮挡／GI 或本机 GPU 性能验收。

`hud-live.json` 记录实际连续帧下的浮层读数。其帧率来自并行测试中的 Linux 软件 WebGL，不是 RTX4070Ti 基准。显存仅为场景缓冲／纹理估算，不含驱动或渲染目标。

`large-world-render.*` 验证实际 4096m / 97网格视野，天空半径小于远裁剪，无页面错误；综合测试另验证尺寸输入、保持 33网格预算、撤销／重做／载入，以及暂时缩小地形后保存载入不丢失已有大河道。

`road-performance.json` 保持旧道路专项：像素差0、局部只重建1条／远处0条、同三角数批处理356→82 draw calls、18次支撑缓存命中。不承诺自动交通／光斑开启时等同于旧场景负载。

旧附属灯开关／间距／手摆灯、三维高程、地形生成、匝道路由、12视角中央带与GPU反向seek／真实PNG／连续参数编辑均已另行回归。Windows安装启动、模型文件夹与前端哈希证据在最终包构建后另存。
