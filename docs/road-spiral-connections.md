# 上层接头与近距离螺旋匝道

2026-10-28，1.7.1 之后的修复／新增功能。旧 1.7.1 安装包不包含本轮改动；新版安装包状态以 [Windows 下载与验证](desktop-windows.md) 为准。

## 操作

「自动连接道路」新增连接方式：

- **自动**（默认）：先搜索短连接；整路标记先搜索沿路更合适的站位。没有可行短连接时，才尝试有高差的高速相关螺旋匝道。
- **仅短连接**：保持原来的不绕大圈策略；坡度／空间不足就拒绝。
- **尝试螺旋匝道**：即使短连接可行，也搜索环绕候选。需要足够占地和高差，不保证必定成功。

标记 A/B 后生成即可，不用逐点画圈。旧自动匝道不会静默改线：选中它，选择连接方式，再点 **重新生成这条连接**。保持道路 ID 和机位目标，一步撤销。保存记录包含模式、路线形态、引道长度，以及螺旋半径／转角／设计间隔。

## 上层接头的几何修复

仅把端点斜率设成零，并不能保证整幅匝道离开高速铺装前都不下降；旧补面又将主路与下降坡混合，造成上层缺口、下陷和穿插。

1. 匝道完整断面离开主路边缘之前，跟随主路的设计标高。不是只抬高端点；倾斜／曲线主路使用局部站位投影，不强制拉成一个水平高度。
2. 自动 merge 连接由原高速铺装拥有主路路面，补面在高速范围内跟随主路且位于其下。匝道与主路重叠的同层路面、侧带和标线按有限曲线走廊裁掉，不留共面双铺装。
3. 主路护栏／标线只在实际匝道走廊开口；清理完整护栏高度，避免只切掉下半截而留下悬空残段。中央带、对向车道和真实上下层保持。
4. 新所有权规则只用于自动 merge；老的手绘坡路继续保留原端头接入规则，避免破坏既有三维工程。

旧曲线要点重生成，才能重新计算离开主路前的引道高程。

## 螺旋不是原来的大 U 偏移

使用相切圆弧—直线—圆弧与进出引道搜索环绕路线，双向尝试转弯与布置；通常是部分或一圈多的环绕下降，不承诺每条都是单圆心整圈。

- 最小中心线半径至少 12m，随路宽／高差增加；累计圆弧转角限制 0.75–2 圈，总长不超过 600m。
- 引道跟随各自主路标高，在环绕段消化高差；实际纵坡仍不超过约 18%。
- 螺旋对非相邻路幅及已有道路预留 **5.5m 设计标高间隔**，考虑路面／支撑横梁厚度，为约 4.5m 名义净空留余量；不是工程认证的净空校核。支撑仍走既有全体积避障流程。
- 检查实际路宽、非相邻线段距离及对应高度，不允许同层圈线交叉或路幅互压；高差不足 5.5m 时不强行生成此类螺旋。
- 遵守地形边界、道路和场景物体避障。占地或净空不足，原工程与撤销栈不变。搜索是有限候选，不代表所有可行工程路线都能找到。
- 螺旋的下穿位置不应误建第二个汇入口：有高差的中段不能借用端点意图被误判为同层连接。

仍是布景道路工具，不是交通流方向仿真、工程车道组织或道路规范设计。

## 验证

`npm run test:road-spiral`：

- 纯测：8 组反射／反选顺序、精确端点与相切引道、半径／圈数／坡度预算、断面立体间隔、边界／障碍／低高差拒绝；原短连接限制保持。
- 浏览器：20m／34m 高速、两侧、两创建顺序的 8 组上层接头。原高速车行面密集射线无洞，补面不抬起主路，主路范围内没有匝道重复铺装，接入护栏不穿过入口；缝口误差阈值仍为 0.16m。
- 倾斜高速引道跟随局部设计高度，不被拉平。
- 8 组近距离螺旋：实际曲线纵坡、只保留上下两个汇入口、缝口射线、默认自动回退；真实模式选择／重生成按钮、单次撤销／重做、连接先于主路的保存恢复。
- 「仅短连接」和小地形无螺旋空间时，失败均不改工程及撤销栈。

专项在网页、断网离线 HTML、桌面 CSP 前端运行；证据位于 `road-spiral-evidence/`。原 A/B 自动连接、12 组三维坡路、绿色高度柄、曲线高速／对向与中央带保护、锐角缝口及中央带绘制顺序负对照回归另行保留。平台为 Linux Chromium 软件 WebGL，不等于用户 Windows／4070Ti 或真实 GGUF 验收。
