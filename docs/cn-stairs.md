# 中式古建楼梯：斜边垂带石

按用户上传宝塔底座的楼梯语言，把原先沿整跑楼梯竖立的两堵等高长方体墙改为顺踏步下降的斜边侧帮。不是将长方体整块旋转，也不是单张悬空斜板：侧帮是底部落在地面／本段平台上的封闭实体，上沿从梯头向梯脚线性下降。

## 本次范围

- 宫殿大殿、歇山殿宇：台阶两侧垂带石改为斜边；两／三层台基按上、下跑分别落在对应平台上，不从上层穿到地面。御路斜石、原踏步和台基层级关系保留。
- 院落：其中复用上述殿宇 builder 的阶梯自动采用新侧帮。
- 城门楼：登城马道侧墙改为顺坡垂带石，保留原来的反向攀登方向与梯头平台。
- 城墙敌台：登城步梯两侧改斜边，梯头的短平台护栏保留。
- 夯土台基：登台阶梯侧帮改斜边；前侧顶栏在楼梯出口留口，避免上完楼梯仍被横栏挡住。最窄4米台宽亦检查通过。

未改建筑主体、材质配色、模型库名称／key／数量、参数字段与关闭楼梯的开关。牌坊、石像生等保留件不变；桥头八字挡土墙、建筑山墙和城墙本体不是楼梯夹墙，本次没有一概削掉。上传宝塔及其木构变体的原始几何不改。

## 使用与版本

当前网页、离线 `previz-lab.html` 和桌面前端构建已更新。模型库中重新放置这些建筑即使用新样式；已有程序化模型可重新打开工程或重建模型以更新。不会擅自修改已导入的外部GLB／glTF网格。

旧版Windows安装器未重打包，不会因源码更新而自动改变。桌面前端CSP预检不是Windows原生WebView2／显卡验收。

## 实现与验证

- `src/cn-stairs.js`：两种前后方向通用的封闭楔形实体，独立米制UV，沿用建筑石材和投影；不占用楼梯通道。
- `src/arch.js`：只替换相应楼梯侧墙，适配多层落脚面；保留既有踏步实体与顶平台。
- `npm run test:cn-stairs`：验证顺／逆向、抬高落脚面、高低台基、射线实测线性斜顶、每边双面相邻的封闭网格与实体体积；浏览器检查5类建筑和参数极值、19个中式条目可构建、楼梯开关、出口开口、复制／删除／撤销、JSON与`.previz`往返、精度重建、PNG及短视频导出。
- 同样浏览器回归已在联网开发页、完全离线 `file://` HTML、模拟Tauri CSP桌面前端通过：`cn-stairs-evidence/web.json`、`file.json`、`desktop-csp.json`。均无脚本错误、CSP违规、额外网络请求。平台为Linux Chromium，非原生Windows。
- 木构宝塔、镜头剪辑、时间轴轨道高度／关键帧可见性回归通过。

`cn-stairs-evidence/` 内分别保留夯土台基、单层／多层殿宇的修改前后实际渲染截图；相机、材质、光照一致，不是生成示意图。默认运行 `bash test/withchrome.sh node test/cn-stairs-preview.mjs` 只刷新修改后图，避免覆盖修改前证据。
