# 1.2.0 新手指引

## 用户体验

- 首次启动自动显示欢迎卡，可立即跳过；跳过 / 完成的状态保存在当前应用本地，刷新不再重复弹出。
- 从「操作 · 右键 → 工具 / 工程 → 新手指引」重开；原 `?` 帮助面板也有启动入口。顶栏仍保持七个按钮。
- 九步导览：场景生成、模型库与分组、右键菜单、机位、Direct 镜头剪辑、Generate 参考资料、Export、工程保存、开始创作。
- 自动定位实际入口并高亮；支持上一步、下一步、Esc 跳过、Tab 焦点循环以及窗口缩放。卡片在 800×600 等窄窗口中避让。
- 指引不自动生成场景、不添加模型或机位、不导出、不调用 AI；结束恢复原页面、模型库展开状态、滚动位置、视角与焦点。不占用撤销，也不改变选择和工程内容。
- 播放、预览、导出、参考采样、地形任务或笔刷期间不打开导览。其他对话框打开时提示先关闭，避免叠加操作。
- 首访导览替代旧的自动弹出「一句话生成」，不会同时叠两层弹窗；生成入口本身不变。

## 实现与测试

实现：`src/onboarding.js`，由 `src/main.js` 装配；样式在 `src/styles.css`。

`npm run test:onboarding` 在开发网页、断网 `file://` 单 HTML、带桌面 CSP 的前端预览均通过。
报告和实拍界面：`docs/onboarding-evidence/`。

覆盖：模拟真实首访自动出现、跳过后刷新不再出现、工具面板重开、全部九步、前进 / 后退、键盘焦点及 Esc、800×600 窄窗、存储写入被拒仍可关闭、导出只读保护，以及导览前后工程序列化、选择、撤销步数、页面、模型库及相机视角相同。三平台 pageerror / CSP violation 为空。

其他已通过：桌面配置与模拟 IPC 浏览器回归、右键菜单及生成框回归、相机剪辑与时间轴交互 / 视频导出、完整模型库持久化回归、灰模 / 木构宝塔源几何与独立资源、斜边楼梯实体和射线轮廓、饼菜单边缘避让。已构建网页版、离线 HTML 和桌面前端。

浏览器测试环境是 Linux Chromium；不冒充用户电脑上的 Windows / WebView2 全功能验收。Windows 安装包另经 GitHub Windows runner 构建，原生安装 / 窗口冒烟结果及实际包哈希见 `desktop-windows.md` 的 1.2.0 记录。
