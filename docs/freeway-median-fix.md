# 网页高速中央区域转视角闪烁修复

2026-10-27，1.7.0 后续开发修复。**已更新网页源码和离线 HTML；已重新构建桌面前端，但没有重新发布 Windows 安装包。之前下载的 1.7.0 安装包不包含本次修复。**

## 原因和改动

分项截面的高速先生成全宽沥青板，再在同一顶面标高生成中央带。中央带外露部分同时拥有两层共面顶面，产生深度冲突。高速半圆尽端也有相同问题。

- 两侧车行铺装分别生成，中央 4m 只由中央带拥有，不靠抬高面片、polygonOffset 或关闭深度测试掩盖。
- 尽端沥青改为中央带外的环带，中央圆盘只生成一次，同时覆盖旧工程的高速端头。
- 不改道路高度、车道宽度、中央墙或工程数据；加载旧工程时重建几何即可生效，不需要重画道路。

## 验证

- 新增纯几何回归，修复前中央采样点同时命中 2 层顶面而失败，修复后只命中 1 层。覆盖 2/4/6 车道、启用／停用合批、两侧车行面及新旧尽端。
- 实际 WebGL 渲染检查 12 组相机角度／高度，改变绘制顺序后中央带**内部**像素差为 0；重新制造旧版重叠面作为负对照，检测到 95 个中央内部差异像素。精确边界的少量光栅化像素单独记录，不冒充全画面完全一致。
- 完整合批道路与两个尽端的射线均只有一个中央顶面；分项截面高速匝道近侧口打开，中央墙与对向车道保留。
- 原有 40 组三维端点接入纯测、60 组坡度不变路口纯测、12 组实际三维匝道网络、自动 A/B 连接／保存／撤销回归通过。
- `npm run all`、`npm run build:desktop` 通过。

命令：`npm run test:freeway-median`。浏览器证据：[web.json](freeway-median-evidence/web.json)。平台为 Linux Chromium / software WebGL，不是用户 Windows 或 4070Ti 原生验收。
