# 程序化道路连接与独立横断面（1.7.0）

## 标记 A → 标记 B → 自动生成

场景中已有两条道路时，在右侧物体检查器顶部可直接看到「自动连接道路」；地形页的道路工具也有同样入口。

1. 点击「标记道路 A」并点击第一条路，再标记道路 B。程序在端头与对方道路之间寻找接点，不必手工逐点画连接曲线。
2. 要指定位置，改用「标记连接点 A／B」，点击路面上的任意接点或蓝色控制点。两个端点可以分别使用道路模式与接点模式；同一路上不同接点也可连接。
3. 点击「自动生成连接」。程序计算弯道、按水平弧长插值的高程过渡，整路模式还会沿目标道路搜索更合适的接点；不再靠大圈延长短坡。绿色 A、橙色 B 标记只用于操作，不保存为模型。
4. Ctrl+Z 一步撤销整次生成，Ctrl+Shift+Z 重做；结果、分项截面和接入记录随工程保存。Esc 退出标记，清除标记不改动场景。

连接路默认沿用 A 的车道分项；高速接入改用固定 3.5m 单车道、每侧最多 0.75m 路肩（按目标方向的可用宽度自动缩小）、无步道的紧凑单向匝道，只接近侧车道，避开中央隔离带。两条高速之间也通过普通匝道连接，不直接开贯通中央带的十字口。

自动搜索有边界：目标最大纵坡约 18%，限制过紧转弯、自相交、地形范围、与已有道路／物体的净空；无可行路线时明确提示，不产生半成品或额外撤销记录。道路必须可见、解锁且允许接入。它是布景近似，不是工程设计或完整交通规划，也不保证任意两点总能连通。

生成后仍可修改路径和截面。接入记录是生成来源记录，**不是实时约束**：之后移动目标道路不会自动重算连接。选中自动连接道路后，可点「重新生成这条连接」按保存的两个接点重算；空间不够时保留原路，也可重新标记两条路来搜索新的接点。

## 车道不再随总宽度拉伸

车道路使用独立输入：

- **车道总数**：双向道路均分两侧，按 2 递增；单向路按 1 递增。
- **单车道宽**：固定以米计，改变车道数、路肩或步道不会拉宽它。
- **单侧路肩宽**、**单侧步道宽**：分别设置。高速无步道，中央隔离带维持 4m。
- 总宽度是计算结果，不再提供整体宽度滑块。缘石、标线位置／数量、尽端、路口、地形走廊和保存数据采用同一截面。
- 花园小径／碎石路不是标准机动车道，保留单独的铺装宽度输入。
- 旧工程未含分项截面时保留原始几何，不在载入时擅自改变。修改任一分项才切换到明确截面；支持逐项一次撤销。
- 通过 RoadBrush 属性 API 发出的兼容总宽度请求作用于已采用分项截面的道路时，转换为车道数，不拉伸固定单车道宽。

## 锐角口为何缩小

锐角不再把整个凸包按 `1/sin(交角)` 撑成长宽大面片：改用有界小接头，保留外围原道路走廊，仅沿真实相交车行面裁掉穿入的侧带和重复标线。高度受限裁切保护上下层，高程场按真实出口计算，3cm 搭接吸收浮点边界缝。高速保留中央带与对向道路。

原有蓝点平面编辑、每点绿色独立高度手柄、路灯、桥墩、撤销、保存重载继续可用。

详见 [匝道路线与地面汇入口修复](road-ramp-routing-fix.md)。旧工程中的已存曲线不会静默改线，需主动点「重新生成这条连接」；保留 ID、机位目标，支持一步撤销。之前发布的 Windows 1.7.0 安装包尚不含这些后续修复。
