# 路口远景 / 锐角回归

运行：`bash test/withchrome.sh node test/junction-regression.mjs`

- 两条 12m 沥青直路，分别长 360m；测试 90/60/45/30/20/15 度。
- 每个角度必须有四个步道角块，所有几何坐标有限。
- 三档相机高度（最远 600m）、两档俯视倾角，读取四个角块内部的像素，断言仍是浅色步道而非底面。
- 总计 144 个角块像素断言，浏览器不得有 pageerror。
- 已加入 `runsuite.sh`。

## 原因与修复

1. 底面有负 polygonOffset，步道没有。距离增大后，底面的深度偏移超过真实高差，反盖步道。步道和路缘墙采用相同偏移，步道在底面后提交；不禁用深度测试、不用强制置顶。
2. 出口距离固定为半车道宽+6.5，30/45 度时车行边线交点位于轮廓外，两个锐角步道被裁掉。出口改按相邻臂边线交点、最外侧带交点及 R5 切线长度计算；裁切、斑马和停止线共享该出口距离。
3. 更锐的交角需要更长的路口：12m 同宽路的出口距交点约为 90°=12.5m、45°=28.1m、30°=42.6m、15°=85.1m。15/20 度验收使用上述长直路；短路和相邻多个路口的空间争用不在这项回归覆盖范围。
