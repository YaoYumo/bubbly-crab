# 等宽半圆端头回归

运行：`bash test/withchrome.sh node test/road-endcap-regression.mjs`

## 设计

- 画笔自由端不再摆模型库的 cul_de_sac（固定 8.5m 颈宽、大圆盘、矩形基座）。独立库模型保持不动。
- 新的 `src/road-endcap.js` 使用实际路件横断面生成半圆；城市道路车行半径 = 实际车行宽 / 2，外侧依次为 0.45m 路缘、1.8m 步道。
- 车行面/路缘/步道/白色边线沿用道路的材质工厂与准确标高；接缝不叠面、不另加遮盖。
- 圆头直径与道路端面重合，方向/坡度取末端实际跨段；与道路共享 +0.02m 标高偏置。
- 接入路口、noJunct 基座、闭环、地图边缘等排除规则保留；短直路不再被误判为闭环。
- 保存结构不增加字段，重新加载/宽度编辑时重新生成。

## 实测

- asphalt / oneway / concrete，车行宽 3 / 6 / 12 / 20m，共 12 组。
- 两端包围盒横宽恰为车行宽 + 4.5m，向外延伸恰为总宽 / 2，无扩大圆盘或矩形地板。
- 两端各取车行面、路缘、步道三个横向点，在接缝前后 3cm 射线采样：无洞，材质颜色相同，标高误差 < 0.01mm。
- 短直路、斜坡、曲线端头接缝及保存恢复通过。
- 6m→20m 宽度编辑自动更新圆头；取消后恢复原尺寸。
- noJunct 无圆头；T 口仅三个真正自由端有圆头。
- T 型 8 例回归、十字路口 144 个远近景可见性断言均再次通过。
- 生产构建通过（仍有既有 bundle 体积警告）；本轮不宣称完整 UI 总门禁全绿。
