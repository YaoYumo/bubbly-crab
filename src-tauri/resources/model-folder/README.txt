PREVIZ LAB local models

Put your downloaded GGUF model here (not inside runtime/llama).
Recommended for RTX 4070 Ti 12GB: Qwen2.5-7B-Instruct, Q4_K_M GGUF.
Download weights from a trusted publisher. PREVIZ LAB does not bundle model weights.
If the model is split, keep all shards together; select the first shard.
Open One-line generation in the application, refresh models, then describe your scene.
The application starts its bundled local engine when you send a message.
No port, API key, Node.js or separate model service configuration is required.
This feature arranges existing catalog assets; it does not create new 3D meshes.
